## 论文题目

**数字化转型对企业创新绩效的影响研究：组织韧性的中介作用与环境动态性的调节效应**

---

## 研究模型

```
                    ┌─────────────┐
                    │  环境动态性  │
                    │    (W)      │
                    └──────┬──────┘
                           │ H4
                           ▼
┌─────────────┐    H1    ┌─────────────┐    H2    ┌─────────────┐
│  数字化转型  │ ───────→ │  组织韧性   │ ───────→ │  创新绩效   │
│    (X)      │          │    (M)      │          │    (Y)      │
└─────────────┘          └─────────────┘          └─────────────┘
        │                                                 ▲
        │                      H3                         │
        └─────────────────────────────────────────────────┘
```

---

## 研究假设

- **H1**：数字化转型对组织韧性具有显著正向影响
- **H2**：组织韧性对创新绩效具有显著正向影响
- **H3**：数字化转型对创新绩效具有显著正向影响
- **H4**：环境动态性正向调节数字化转型与组织韧性之间的关系

## 创新点提炼

1. **理论创新**：将组织韧性引入数字化转型与创新绩效的关系研究，揭示了"数字化转型→组织韧性→创新绩效"的传导机制

2. **情境创新**：聚焦中国制造业企业，检验了数字化转型理论在新兴市场情境的适用性

3. **边界条件**：识别了环境动态性的调节作用，明确了数字化转型发挥作用的情境条件
