## 研究假设

### 基于ECM-ISC的核心假设
- **H1**：期望确认对满意度具有显著正向影响
- **H2**：期望确认对感知有用性具有显著正向影响
- **H3**：感知有用性对满意度具有显著正向影响
- **H4**：满意度对持续使用意愿具有显著正向影响
- **H5**：感知有用性对持续使用意愿具有显著正向影响

### 情境拓展假设
- **H6**：内容质量对持续使用意愿具有显著正向影响
- **H7**：社区互动对持续使用意愿具有显著正向影响
- **H8**：知识焦虑正向调节满意度与持续使用意愿之间的关系

## 量表示例

### 持续使用意愿（Bhattacherjee, 2001）
```
CI1：我打算继续使用这个知识付费平台
CI2：我会继续订阅/购买该平台的知识产品
CI3：相比停止使用，我更愿意继续使用该平台
```

### 内容质量（自编）
```
CQ1：平台提供的内容专业性强
CQ2：平台内容对我的工作/学习很有帮助
CQ3：平台内容更新及时
CQ4：平台内容有深度，不是泛泛而谈
CQ5：平台内容形式丰富（音频、视频、图文等）
CQ6：平台内容能够解决我的实际问题
```

### 知识焦虑（改编）
```
KA1：我经常担心自己的知识跟不上时代
KA2：看到别人学习新知识，我会感到焦虑
KA3：我害怕因为知识不足而被淘汰
KA4：我总觉得自己需要学习更多
```
