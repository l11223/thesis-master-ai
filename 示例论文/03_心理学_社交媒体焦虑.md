## 论文题目

**社交媒体使用对大学生焦虑的影响：上行社会比较的中介作用与自尊的调节效应**

---

## 研究模型

```
                    ┌─────────────┐
                    │    自尊     │
                    │    (W)      │
                    └──────┬──────┘
                           │ H4
                           ▼
┌─────────────┐    H1    ┌─────────────┐    H2    ┌─────────────┐
│社交媒体使用  │ ───────→ │ 上行社会比较 │ ───────→ │    焦虑    │
│    (X)      │          │    (M)      │          │    (Y)      │
└─────────────┘          └─────────────┘          └─────────────┘
   - 使用强度                                        - 状态焦虑
   - 使用类型                                        - 特质焦虑
```

---

## 研究假设

- **H1**：社交媒体使用强度对上行社会比较具有显著正向影响
- **H2**：上行社会比较对焦虑具有显著正向影响
- **H3**：社交媒体使用强度对焦虑具有显著正向影响
- **H4**：自尊负向调节上行社会比较与焦虑之间的关系
- **H5**：上行社会比较在社交媒体使用与焦虑之间起中介作用

## 创新点

1. **机制揭示**：揭示上行社会比较在社交媒体使用与焦虑之间的中介作用

2. **边界条件**：识别自尊的保护性调节作用，为高危人群识别提供依据

3. **本土验证**：在中国大学生群体中验证社会比较理论的适用性
