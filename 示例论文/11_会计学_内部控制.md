## 论文题目

**内部控制质量对企业价值的影响研究：信息披露质量的中介作用与分析师关注度的调节效应**

---

## 研究模型

```
                    ┌─────────────┐
                    │ 分析师关注度 │
                    │    (W)      │
                    └──────┬──────┘
                           │ H4
                           ▼
┌─────────────┐    H1    ┌─────────────┐    H2    ┌─────────────┐
│ 内部控制质量 │ ───────→ │信息披露质量 │ ───────→ │  企业价值   │
│    (X)      │          │    (M)      │          │    (Y)      │
└─────────────┘          └─────────────┘          └─────────────┘
   - 迪博指数                 - 深交所评级            - Tobin's Q
   - 五要素评分               - 盈余质量              - 市净率
        │                                                 ▲
        │                      H3                         │
        └─────────────────────────────────────────────────┘
```

---

## 研究假设

- **H1**：内部控制质量对信息披露质量具有显著正向影响
- **H2**：信息披露质量对企业价值具有显著正向影响
- **H3**：内部控制质量对企业价值具有显著正向影响
- **H4**：分析师关注度正向调节内部控制质量与信息披露质量之间的关系
- **H5**：信息披露质量在内部控制质量与企业价值之间起中介作用

## 论文大纲

### 摘要（800字）
- 研究背景：内部控制建设与资本市场信息效率
- 研究方法：2018-2023年A股上市公司面板数据
- 核心发现：内部控制→信息披露→企业价值的传导机制
- 理论贡献与实践启示

### 第1章 引言（3000字）
1.1 研究背景
- 内部控制规范体系建设
- 上市公司信息披露问题
- 投资者保护与企业价值

1.2 问题提出
- 内部控制如何影响企业价值？
- 信息披露在其中扮演什么角色？

1.3 研究意义
- 理论意义：拓展内部控制经济后果研究

1.4 研究内容与方法

1.5 论文结构安排

### 第3章 研究设计（5000字）
3.1 样本选择与数据来源
- 3.1.1 样本筛选标准
- 3.1.2 数据来源（CSMAR、Wind）
- 3.1.3 样本描述性统计

3.2 变量定义与测量
- 3.2.1 被解释变量：企业价值（Tobin's Q）
- 3.2.2 解释变量：内部控制质量（迪博指数）
- 3.2.3 中介变量：信息披露质量（深交所评级）
- 3.2.4 调节变量：分析师关注度（分析师人数）
- 3.2.5 控制变量（企业规模、资产负债率、盈利能力等）

| 变量 | 符号 | 测量方式 |
|------|------|----------|
| 企业价值 | TobinQ | (市值+负债)/总资产 |
| 内部控制质量 | IC | 迪博指数/100 |
| 信息披露质量 | DQ | 深交所评级（1-4） |
| 分析师关注 | Analyst | Ln(分析师人数+1) |
| 企业规模 | Size | Ln(总资产) |
| 资产负债率 | Lev | 负债/资产 |
| 盈利能力 | ROA | 净利润/总资产 |

3.3 模型设定

- 3.3.2 中介效应检验模型（三步法+Bootstrap）

## 创新点提炼

1. **机制揭示**：揭示了内部控制通过提升信息披露质量进而影响企业价值的传导机制

2. **边界条件**：识别了分析师关注作为外部治理机制对内部控制作用的增强效应

3. **方法创新**：采用多种稳健性检验方法（PSM、IV）处理内生性问题
