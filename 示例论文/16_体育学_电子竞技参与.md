## 论文题目

**电子竞技参与动机对持续参与意愿的影响研究：心流体验的中介作用与社会支持的调节效应**

---

## 研究模型

```
                    ┌─────────────┐
                    │  社会支持   │
                    │    (W)      │
                    │ - 同伴支持  │
                    │ - 家庭支持  │
                    └──────┬──────┘
                           │ H4
                           ▼
┌─────────────┐    H1    ┌─────────────┐    H2    ┌─────────────┐
│ 参与动机    │ ───────→ │  心流体验   │ ───────→ │ 持续参与意愿│
│    (X)      │          │    (M)      │          │    (Y)      │
└─────────────┘          └─────────────┘          └─────────────┘
   - 成就动机               - 专注沉浸             - 行为意向
   - 社交动机               - 技能挑战平衡         - 时间投入
   - 娱乐动机               - 内在享受             - 消费意愿
   - 逃避动机
        │                                                 ▲
        │                      H3                         │
        └─────────────────────────────────────────────────┘
```

---

## 研究假设

### 主效应
- **H1a**：成就动机对心流体验具有显著正向影响
- **H1b**：社交动机对心流体验具有显著正向影响
- **H1c**：娱乐动机对心流体验具有显著正向影响
- **H1d**：逃避动机对心流体验具有显著正向影响
- **H2**：心流体验对持续参与意愿具有显著正向影响
- **H3**：参与动机对持续参与意愿具有显著正向影响

### 中介效应
- **H4**：心流体验在参与动机与持续参与意愿之间起中介作用

### 调节效应
- **H5a**：同伴支持正向调节参与动机与心流体验之间的关系
- **H5b**：家庭支持正向调节参与动机与心流体验之间的关系

## 创新点提炼

1. **理论整合**：将心流理论与使用满足理论整合，构建电竞参与行为的综合模型

2. **机制揭示**：揭示心流体验在参与动机与持续参与意愿之间的中介机制

3. **边界条件**：识别社会支持（同伴vs家庭）的差异化调节作用
