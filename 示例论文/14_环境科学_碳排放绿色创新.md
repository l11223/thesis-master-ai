## 论文题目

**碳排放权交易政策对企业绿色创新的影响研究——基于双重差分模型的实证分析**

---

## 研究模型

```
【双重差分设计】

                时间维度
                │
        ┌───────┴───────┐
        │               │
    政策前          政策后
    (2008-2012)    (2014-2023)
        │               │
        ▼               ▼
┌─────────────┐   ┌─────────────┐
│   试点组     │   │   试点组    │
│ (7省市试点)  │   │ 碳交易政策 │
└─────────────┘   └─────────────┘
        │               │
        │    DID效应    │
        │◄─────────────►│
        │               │
┌─────────────┐   ┌─────────────┐
│   对照组     │   │   对照组    │
│ (非试点地区) │   │ 无政策干预 │
└─────────────┘   └─────────────┘

【机制分析】
碳交易政策 → 成本压力 ─┐
            → 资源配置 ├─→ 绿色创新
            → 信号效应 ─┘
```

---

## 研究假设

- **H1**：碳排放权交易政策对试点地区企业绿色创新具有显著促进作用（波特假说）
- **H2a**：碳交易政策通过提高环境成本倒逼企业绿色创新（成本压力机制）
- **H2b**：碳交易政策通过优化资源配置促进企业绿色创新（资源配置机制）
- **H2c**：碳交易政策通过传递政策信号引导企业绿色创新（信号效应机制）
- **H3**：碳交易政策对绿色创新的促进效应在高碳行业更显著
