```
【组态研究框架】

前因条件：
┌─────────────────────────────────────┐
│  主播特质        │  直播氛围        │

└─────────────────────────────────────┘
                  │
                  ▼
        【冲动购买行为】
          高冲动 / 低冲动
```

## 研究问题

1. 哪些因素组合会导致消费者高冲动购买？
2. 哪些因素组合会导致消费者低冲动购买？
3. 不同路径之间的等效性如何？
