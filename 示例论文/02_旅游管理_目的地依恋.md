## 论文题目

**多感官体验对旅游目的地依恋的影响研究：情感记忆的中介作用与旅游涉入度的调节效应**

---

## 研究模型

```
                    ┌─────────────┐
                    │  旅游涉入度  │
                    │    (W)      │
                    └──────┬──────┘
                           │ H4
                           ▼
┌─────────────┐    H1    ┌─────────────┐    H2    ┌─────────────┐
│ 多感官体验   │ ───────→ │   情感记忆  │ ───────→ │ 目的地依恋  │
│    (X)      │          │    (M)      │          │    (Y)      │
└─────────────┘          └─────────────┘          └─────────────┘
   - 视觉                                            - 地方依赖
   - 听觉                                            - 地方认同
   - 嗅觉
   - 味觉
   - 触觉
```

---

## 研究假设

- **H1**：多感官体验对情感记忆具有显著正向影响
  - H1a：视觉体验对情感记忆有正向影响
  - H1b：听觉体验对情感记忆有正向影响
  - H1c：嗅觉体验对情感记忆有正向影响
  - H1d：味觉体验对情感记忆有正向影响
  - H1e：触觉体验对情感记忆有正向影响
- **H2**：情感记忆对目的地依恋具有显著正向影响
- **H3**：多感官体验对目的地依恋具有显著正向影响
- **H4**：旅游涉入度正向调节多感官体验与情感记忆的关系

## 创新点

1. **视角创新**：首次系统检验五种感官体验对目的地依恋的差异化影响

2. **机制揭示**：揭示了"多感官体验→情感记忆→目的地依恋"的作用机制

3. **情境贡献**：以世界文化遗产地为研究情境，丰富了遗产旅游研究
