## 论文题目

**城市社区老年人健康素养对健康行为的影响研究：健康自我效能的中介作用与社会资本的调节效应**

---

## 研究模型

```
                    ┌─────────────┐
                    │  社会资本   │
                    │    (W)      │
                    │ - 社会信任  │
                    │ - 社会参与  │
                    │ - 社会网络  │
                    └──────┬──────┘
                           │ H4
                           ▼
┌─────────────┐    H1    ┌─────────────┐    H2    ┌─────────────┐
│ 健康素养    │ ───────→ │健康自我效能 │ ───────→ │  健康行为   │
│    (X)      │          │    (M)      │          │    (Y)      │
└─────────────┘          └─────────────┘          └─────────────┘
   - 功能性               - 疾病管理信心           - 合理膳食
   - 互动性               - 健康促进信心           - 适量运动
   - 批判性               - 医疗决策信心           - 戒烟限酒
                                                   - 定期体检
        │                                                 ▲
        │                      H3                         │
        └─────────────────────────────────────────────────┘
```

---

## 研究假设

- **H1**：健康素养对健康自我效能具有显著正向影响
  - H1a：功能性健康素养对健康自我效能有正向影响
  - H1b：互动性健康素养对健康自我效能有正向影响
  - H1c：批判性健康素养对健康自我效能有正向影响
- **H2**：健康自我效能对健康行为具有显著正向影响
- **H3**：健康素养对健康行为具有显著正向影响
- **H4**：社会资本正向调节健康素养与健康自我效能之间的关系
- **H5**：健康自我效能在健康素养与健康行为之间起中介作用

### 第3章 研究对象与方法（5000字）
3.1 研究设计
- 横断面调查研究

3.2 研究对象
- 3.2.1 纳入标准
  - 年龄≥60岁
  - 本市常住居民（≥6个月）
  - 知情同意
- 3.2.2 排除标准
  - 认知障碍（MMSE<24分）
  - 严重听力/视力障碍
  - 无法完成问卷者

3.3 样本量计算
- 多因素回归分析
- α=0.05, β=0.10, 效应量f²=0.15
- 计算样本量：850人

3.4 抽样方法
- 分层随机抽样
- 3个城区 × 4个社区 × 每社区约70人

3.5 数据收集

## 样本分层设计

```
【分层随机抽样方案】

城市（某省会城市）
├── 城区A（中心城区）
│   ├── 社区A1（70人）
│   ├── 社区A2（70人）
│   ├── 社区A3（70人）
│   └── 社区A4（70人）
├── 城区B（新开发区）
│   ├── 社区B1（70人）
│   ├── 社区B2（70人）
│   ├── 社区B3（70人）
│   └── 社区B4（70人）
└── 城区C（老城区）
    ├── 社区C1（70人）
    ├── 社区C2（70人）
```
