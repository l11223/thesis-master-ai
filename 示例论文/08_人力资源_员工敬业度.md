## 论文题目

**包容型领导对员工敬业度的跨层次影响研究：心理安全感的中介作用与团队异质性的调节效应**

---

## 研究模型

```
【跨层次研究模型】

团队层面（Level-2）
┌─────────────────────────────────────────────┐
│                                             │
│    包容型领导 ────────────────→ 团队异质性   │
│        │                          │        │
│        │ H1                       │ H4     │
│        ▼                          ▼        │
└────────┼──────────────────────────┼────────┘
         │                          │
─────────┼──────────────────────────┼─────────
         │                          │
┌────────┼──────────────────────────┼────────┐
│        ▼                          ▼        │
│   心理安全感 ──────H2──────→ 员工敬业度    │
│                                             │
│                    H3                       │
│    （包容型领导 → 心理安全感 → 敬业度）     │
│                                             │
└─────────────────────────────────────────────┘
个体层面（Level-1）
```

---

## 研究假设

- **H1**：包容型领导对员工心理安全感具有显著正向跨层次影响
- **H2**：心理安全感对员工敬业度具有显著正向影响
- **H3**：心理安全感在包容型领导与员工敬业度之间起跨层次中介作用
- **H4**：团队异质性正向调节包容型领导与心理安全感之间的关系

## HLM操作要点

```
【Mplus语法示例】

TITLE: Cross-level mediation;
DATA: FILE IS data.dat;
VARIABLE:
  NAMES ARE team id IL PS EE control;
  CLUSTER = team;
  WITHIN = PS EE control;
  BETWEEN = IL;
ANALYSIS:
  TYPE = TWOLEVEL;
MODEL:
  %WITHIN%
  EE ON PS control;
  %BETWEEN%
  EE ON IL;
  PS ON IL;
OUTPUT: SAMPSTAT CINTERVAL;
```
