## 论文题目

**ESG评级对基金投资绩效的影响研究：投资者情绪的中介作用与市场周期的调节效应**

---

## 研究模型

```
                    ┌─────────────┐
                    │  市场周期   │
                    │    (W)      │
                    │ 牛市/熊市   │
                    └──────┬──────┘
                           │ H4
                           ▼
┌─────────────┐    H1    ┌─────────────┐    H2    ┌─────────────┐
│  ESG评级    │ ───────→ │ 投资者情绪  │ ───────→ │  投资绩效   │
│    (X)      │          │    (M)      │          │    (Y)      │
└─────────────┘          └─────────────┘          └─────────────┘
   - 综合评级                - 资金净流入            - 收益率
   - E/S/G分项               - 换手率               - 夏普比率
                                                    - 最大回撤
        │                                                 ▲
        │                      H3                         │
        └─────────────────────────────────────────────────┘
```

---

## 研究假设

- **H1**：ESG评级对投资者情绪具有显著正向影响
- **H2**：投资者情绪对基金投资绩效具有显著正向影响
- **H3**：ESG评级对基金投资绩效具有显著正向影响
- **H4a**：在熊市中，ESG评级对投资绩效的正向影响更强（风险规避效应）
- **H4b**：在牛市中，ESG评级对投资绩效的正向影响更弱（机会成本效应）
- **H5**：投资者情绪在ESG评级与投资绩效之间起部分中介作用

## 创新点提炼

1. **视角创新**：从投资者情绪角度解释ESG评级的绩效效应，弥合理性与行为金融视角

2. **情境贡献**：识别市场周期对ESG策略有效性的调节作用，揭示"熊市保护"效应

3. **方法创新**：采用马尔科夫区制转换模型客观界定牛熊市，避免主观划分偏误
