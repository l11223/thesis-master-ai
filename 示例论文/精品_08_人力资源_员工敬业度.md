## 论文题目

**包容型领导对员工敬业度的跨层次影响研究：心理安全感的中介作用与团队异质性的调节效应**

---

## 研究问题与目标

1. 包容型领导是否能提升员工敬业度？  
2. 心理安全感是否发挥跨层次中介作用？  
3. 团队异质性是否调节领导影响路径？  

---

## 跨层次研究模型

```
团队层面（Level-2）
┌─────────────────────────────────────────────┐
│    包容型领导 ────────────────→ 团队异质性   │
│        │                          │        │
│        │ H1                       │ H4     │
│        ▼                          ▼        │
└────────┼──────────────────────────┼────────┘
         │                          │
─────────┼──────────────────────────┼─────────
         │                          │
┌────────┼──────────────────────────┼────────┐
│        ▼                          ▼        │
│   心理安全感 ──────H2──────→ 员工敬业度    │
│                                             │
│                    H3                       │
│    （包容型领导 → 心理安全感 → 敬业度）     │
└─────────────────────────────────────────────┘
个体层面（Level-1）
```

---

## 研究假设

- **H1**：包容型领导对员工心理安全感具有显著正向跨层次影响  
- **H2**：心理安全感对员工敬业度具有显著正向影响  
- **H3**：心理安全感在包容型领导与员工敬业度之间起跨层次中介作用  
- **H4**：团队异质性正向调节包容型领导与心理安全感之间的关系  

---

## 变量与测量（示例框架）

| 变量 | 层次 | 定义要点 | 备注 |
|------|------|----------|------|
| 包容型领导 | L2 | 领导的开放、尊重与支持行为 | 团队层变量 |
| 心理安全感 | L1 | 员工表达与尝试的安全感 | 个体层变量 |
| 员工敬业度 | L1 | 工作投入与活力水平 | 个体层变量 |
| 团队异质性 | L2 | 团队成员差异程度 | 客观指标或问卷 |

---

## 研究设计

- **样本与数据**：多家企业团队数据，计划团队样本 ≥ 40，成员 ≥ 200  
- **数据配对**：领导与成员分时段填写，减少共同方法偏差  
- **控制变量**：性别、年龄、工龄、团队规模  
- **数据聚合检验**：rwg、ICC(1)、ICC(2)  

---

## 数据分析计划

| 分析内容 | 工具 | 预期输出 |
|----------|------|----------|

| 中介检验 | Monte Carlo | 间接效应 |
