## 论文题目

**ESG表现对企业价值的影响研究：融资约束的中介作用与分析师关注的调节效应**

---

## 研究框架

```
【理论模型】

                    ┌─────────────┐
                    │  分析师关注  │
                    │    (W)      │
                    └──────┬──────┘
                           │ H4
                           ▼
┌─────────────┐    H1    ┌─────────────┐    H2    ┌─────────────┐
│  ESG表现    │ ───────→ │   融资约束  │ ───────→ │   企业价值  │
│    (X)      │          │    (M)      │          │    (Y)      │
└─────────────┘          └─────────────┘          └─────────────┘
   - E（环境）                                       - Tobin's Q
   - S（社会）                                       - 市值/账面比
   - G（治理）
        │                      H3                         ▲
        └─────────────────────────────────────────────────┘
```

---

## 研究假设

- **H1**：ESG表现对融资约束具有显著负向影响（即ESG表现越好，融资约束越低）
- **H2**：融资约束对企业价值具有显著负向影响
- **H3**：ESG表现对企业价值具有显著正向影响
- **H3a**：ESG各维度（E/S/G）对企业价值的影响存在差异
- **H4**：分析师关注正向调节ESG表现与融资约束之间的关系

## Stata代码示例

```stata
* 数据预处理
winsor2 TobinQ ESG SA, cuts(1 99) replace

* 基准回归
reghdfe TobinQ ESG Size Lev ROA Growth Top1 Dual SOE, absorb(id year) vce(cluster id)

* 中介效应检验
sgmediation TobinQ, mv(SA) iv(ESG) cv(Size Lev ROA Growth)

* 调节效应检验
gen ESG_Analyst = ESG * Analyst
reghdfe SA ESG Analyst ESG_Analyst $controls, absorb(id year) vce(cluster id)

* PSM-DID
psmatch2 ESG_upgrade Size Lev ROA Growth, neighbor(1) common
diff TobinQ, t(ESG_upgrade) p(post) cov(Size Lev ROA)
```
