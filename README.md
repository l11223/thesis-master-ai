一套面向本硕博研究者的 AI 辅助学术写作系统。提供结构化提示词引擎、90 个学科方向的完整论文范例，以及从选题到投稿的全流程工具链。

兼容 Claude、ChatGPT、通义千问等主流大语言模型，覆盖 SCI / SSCI / CSSCI 投稿规范。

## 核心特性

|  | 特性 | 说明 |
|:---:|:---|:---|
| 📖 | **结构化提示词引擎** | 融合 25 位学术领域专家知识，涵盖选题、文献、方法、写作、投稿全阶段 |
| 📊 | **多元研究方法支持** | 定量分析、质性研究、混合方法、fsQCA、HLM、PRISMA 系统综述 |
| 📝 | **学术英语句型库** | 100+ 高频学术短语，覆盖 Hedging、论证、过渡等核心场景 |
| 🔬 | **审稿人视角模块** | 模拟同行评审，提前发现论文结构与论证薄弱环节 |
| 📁 | **90 学科论文范例** | 100 篇完整学术论文，按学科分类，可直接参考结构与写法 |
| 🛠️ | **写作工具链** | 论文模板、文献矩阵、诊断清单、一键新建论文脚本 |

## 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/YourUsername/academic-paper-writing-system.git

# 2. 将提示词发送给 AI
#    打开 THESIS_MASTER_PROMPT.md，全选复制，粘贴到 Claude / ChatGPT / 通义千问

# 3. 按引导开始写作
#    AI 会询问论文类型、学科方向、研究主题，回答后即可开始
```

> 如果 AI 提示内容过长，可使用精简版 `QUICK_START.md`。

## 核心模块

### 提示词引擎 · THESIS_MASTER_PROMPT

系统的核心组件，通过结构化 Prompt 引导 AI 完成学术写作全流程。

| 模块 | 内容 |
|:---|:---|
| 学术大师知识库 | 25 位领域专家的方法论与写作范式 |
| 研究方法速查 | SPSS / SmartPLS / Mplus / AMOS 操作指引 |
| 量表开发流程 | EFA → CFA → 信效度检验完整链路 |
| fsQCA 分析 | 校准 → 必要条件 → 真值表 → 组态解读 |
| PRISMA 2020 | 系统综述 27 项清单 + 流程图模板 |
| HLM 多层模型 | 零模型 → 随机截距 → 随机斜率 → 跨层交互 |
| SCI 投稿规范 | 格式检查、图表标准、必备声明、拒稿对策 |
| 学术英语句型 | 100+ 短语，覆盖论证、过渡、Hedging 等场景 |
| 创新点提炼 | 四种贡献类型：拓展 / 整合 / 修正 / 建构 |
| 审稿人视角 | 模拟同行评审，定位论文薄弱环节 |

### 论文范例库

100 篇完整学术论文，覆盖 90 个学科方向。每篇包含完整的研究框架、文献综述、方法设计、数据分析与结论讨论，可直接参考论文结构与学术表达。

- **分章节版**（`完整论文/`）：10 个基础学科，按章节拆分，便于逐段学习
- **完整版**（`完整论文精品集/`）：80 个扩展学科，单文件完整论文

## 使用指南

### 常用指令

在与 AI 对话过程中，可随时使用以下指令切换工作模式：

| 指令 | 功能 |
|:---|:---|
| `继续` | 继续撰写下一节内容 |
| `量表开发` | 进入量表设计与验证流程 |
| `fsQCA` | 进入定性比较分析引导 |
| `审稿人视角` | 以审稿人身份审查当前论文 |
| `投稿检查` | 执行投稿前完整检查清单 |
| `PRISMA` | 进入系统综述写作流程 |

### 新建论文项目

```bash
./new_thesis.sh "论文主题"
```

脚本会自动创建包含标准目录结构的论文项目文件夹。

> 更多使用细节请参阅 [使用指南.md](使用指南.md) 和 [诊断清单.md](诊断清单.md)。

## 注意事项

- **学术诚信**：本系统定位为写作辅助工具，AI 辅助不等于 AI 代写，请确保研究的原创性与学术规范
- **格式规范**：约 35% 的初审退稿源于格式问题，投稿前务必使用诊断清单逐项检查
- **图表标准**：照片类 ≥ 300 dpi，线图类 ≥ 600 dpi，优先使用 TIFF / EPS / PDF 格式
- **学术表达**：注意 Hedging Language 的使用，避免过于绝对的表述
