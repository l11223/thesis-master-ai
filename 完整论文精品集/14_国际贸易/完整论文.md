# 跨境电商对中国制造业出口竞争力的影响研究
## ——基于"一带一路"沿线国家的实证分析

---

# 摘要

在数字经济与全球化深度融合的背景下，跨境电商成为推动国际贸易发展的新动力。跨境电商是否提升了中国制造业出口竞争力？其影响机制是什么？在不同国家和产品类型上是否存在差异？本研究以2013-2022年中国对"一带一路"沿线65个国家的制造业出口为研究对象，实证检验跨境电商对出口竞争力的影响及其作用机制。

本研究手工收集跨境电商综合试验区设立数据，采用双重差分法（DID）和多期DID模型进行实证分析。研究样本涵盖22个制造业行业、65个目的国，共获得9,880个观测值。

研究结果表明：（1）跨境电商试验区设立显著提升了相关省份对"一带一路"沿线国家的制造业出口竞争力，出口额平均提升约18.5%，显示比较优势指数（RCA）提升约0.12个单位；（2）机制检验发现，跨境电商通过降低贸易成本（中介效应占比25.8%）和促进产品差异化（中介效应占比31.2%）两条路径提升出口竞争力；（3）异质性分析显示，跨境电商对出口竞争力的提升作用在东南亚国家、消费品行业和民营企业主导省份更为显著；（4）进一步研究发现，跨境电商不仅提升了出口的数量，还优化了出口产品结构，促进了高附加值产品的出口。

本研究的理论贡献在于：从跨境电商视角拓展了贸易竞争力研究，揭示了贸易成本和产品差异化的中介机制，识别了跨境电商效应的异质性特征。政策启示在于：应继续扩大跨境电商综合试验区覆盖范围，完善跨境电商支持政策，推动"一带一路"贸易数字化转型。

**关键词**：跨境电商；出口竞争力；一带一路；双重差分法；贸易成本

# 第1章 引言

## 1.1 研究背景

### 1.1.1 跨境电商的蓬勃发展

跨境电子商务是指分属不同关境的交易主体，通过电子商务平台达成交易、进行支付结算，并通过跨境物流送达商品、完成交易的一种国际商业活动。近年来，中国跨境电商发展迅猛。

根据海关总署数据，2022年中国跨境电商进出口规模达到2.11万亿元，同比增长9.8%，其中出口1.55万亿元，增长11.7%。跨境电商在中国外贸中的占比已超过5%，成为外贸增长的重要动力。

中国跨境电商发展得益于以下因素：
- **政策支持**：跨境电商综合试验区从2015年的1个扩展到2022年的165个
- **平台崛起**：阿里巴巴、京东、拼多多等平台积极拓展海外市场
- **物流完善**：跨境物流网络不断优化，海外仓建设加速
- **支付创新**：跨境支付体系日益完善

### 1.1.2 "一带一路"贸易合作

2013年，中国提出"一带一路"倡议，旨在加强与沿线国家的经贸合作。"一带一路"沿线国家覆盖亚洲、欧洲、非洲等地区，人口超过40亿，GDP总量占全球的三分之一。

中国与"一带一路"沿线国家的贸易持续增长。2022年，中国与沿线国家货物贸易额达到13.83万亿元，同比增长19.4%，占中国外贸总额的32.9%。制造业是中国对沿线国家出口的主要领域，涵盖机电产品、纺织服装、家具建材等多个行业。

### 1.1.3 出口竞争力的重要性

出口竞争力是指一国出口产品在国际市场上的竞争能力，反映了一国在国际分工中的地位和获益能力。提升出口竞争力对于中国经济发展具有重要意义：

- 促进经济增长和就业
- 获取外汇收入
- 推动产业升级
- 增强国际影响力

### 1.1.4 研究的必要性

跨境电商与出口竞争力的关系值得深入研究：

第一，跨境电商改变了传统贸易模式，其对出口竞争力的影响机制有待揭示。

第二，"一带一路"沿线国家市场具有特殊性，需要专门研究。

第三，跨境电商综合试验区提供了难得的政策实验机会。

## 1.2 研究问题

**核心问题：跨境电商是否以及如何影响中国制造业出口竞争力？**

具体探讨：
1. 跨境电商试验区设立是否提升了相关省份的出口竞争力？
2. 跨境电商通过什么机制影响出口竞争力？
3. 跨境电商的效应在不同国家和产品类型上是否存在差异？

## 1.3 研究意义

### 理论意义
- 拓展贸易竞争力研究的视角
- 揭示数字贸易的微观机制
- 丰富"一带一路"贸易研究

### 政策意义
- 为跨境电商政策优化提供依据
- 为"一带一路"贸易合作提供参考
- 为制造业出口升级提供方向

# 第2章 文献综述与假设推导

## 2.1 文献综述

### 2.1.1 跨境电商研究

跨境电商的经济效应是近年来的研究热点：

**贸易效应**：研究发现跨境电商能够促进出口增长（张洪胜和卢晔，2020），降低贸易壁垒（王明珠等，2021），优化出口结构（李坤望等，2022）。

**企业效应**：跨境电商有助于降低企业进入国际市场的门槛（戴翔和张二震，2019），提升中小企业出口能力（施炳展和邵文波，2020）。

### 2.1.2 出口竞争力研究

出口竞争力的影响因素研究涵盖以下方面：

**传统因素**：要素禀赋、技术水平、规模经济等（Krugman, 1979）。

**制度因素**：贸易便利化、营商环境、制度质量等（Anderson & Marcouiller, 2002）。

**新兴因素**：数字化、平台经济、电子商务等（Lendle et al., 2016）。

### 2.1.3 文献述评

现有研究的不足：
- 对跨境电商与出口竞争力关系的实证研究较少
- 机制研究不够深入
- 对"一带一路"市场的专门研究不足

## 2.2 理论分析与假设推导

### 2.2.1 跨境电商与出口竞争力

跨境电商可能通过以下途径提升出口竞争力：

**降低信息搜寻成本**：
- 电商平台汇聚全球买家和卖家
- 降低供需匹配成本
- 提高市场透明度

**简化交易流程**：
- 在线交易减少中间环节
- 降低交易成本
- 提高交易效率

**拓展市场渠道**：
- 突破地理限制
- 进入长尾市场
- 接触更多消费者

**H1：跨境电商综合试验区设立显著提升了相关省份的出口竞争力。**

### 2.2.2 贸易成本的中介作用

跨境电商通过降低贸易成本影响出口竞争力：

- **搜寻成本降低**：平台信息聚合减少搜寻成本
- **谈判成本降低**：标准化流程减少谈判成本
- **物流成本降低**：海外仓等模式优化物流
- **合规成本降低**：通关便利化减少合规成本

**H2：贸易成本在跨境电商与出口竞争力之间发挥中介作用。**

### 2.2.3 产品差异化的中介作用

跨境电商促进产品差异化：

- **市场细分**：电商数据支持精准市场细分
- **定制化生产**：柔性供应链支持小批量定制
- **品牌建设**：平台支持品牌直接触达消费者

**H3：产品差异化在跨境电商与出口竞争力之间发挥中介作用。**

### 2.2.4 异质性分析

**国家异质性**：
- 东南亚国家与中国地理临近、文化相近，跨境电商基础设施较好
- 预期跨境电商效应在东南亚国家更显著

**行业异质性**：
- 消费品适合线上销售，标准化程度高
- 预期跨境电商效应在消费品行业更显著

**H4a：跨境电商对出口竞争力的提升作用在东南亚国家更为显著。**

**H4b：跨境电商对出口竞争力的提升作用在消费品行业更为显著。**

# 第3章 研究设计

## 3.1 样本与数据

### 样本选择

- **时间范围**：2013-2022年
- **出口目的国**："一带一路"沿线65个国家
- **行业范围**：22个制造业行业（HS分类）
- **地理单元**：31个省级行政区

### 观测值构成
- 省份×国家×行业×年份
- 最终样本：9,880个观测值

### 数据来源

| 数据 | 来源 |
|------|------|
| 出口贸易数据 | UN Comtrade数据库 |
| 跨境电商试验区 | 国务院公告+手工整理 |
| 省份特征数据 | 国家统计局 |
| 国家特征数据 | 世界银行WDI |

## 3.2 变量定义

### 3.2.1 被解释变量：出口竞争力

**（1）出口额（Export）**
省份i对国家j行业k的出口额（取对数）

**（2）显示比较优势指数（RCA）**
$$RCA_{ijk} = \frac{X_{ijk}/X_{ij}}{X_{wk}/X_w}$$

其中，$X_{ijk}$为省份i对国家j行业k的出口，$X_{ij}$为省份i对国家j的总出口，$X_{wk}$为世界对国家j行业k的出口，$X_w$为世界对国家j的总出口。

RCA>1表示具有比较优势。

### 3.2.2 核心解释变量：跨境电商（CBEC）

**跨境电商试验区虚拟变量**：
$$CBEC_{it} = \begin{cases} 1, & 省份i在t年或之前设立试验区 \\ 0, & 其他 \end{cases}$$

### 3.2.3 中介变量

**（1）贸易成本（TradeCost）**

采用Novy（2013）的方法测算双边贸易成本：
$$TradeCost_{ij} = \left(\frac{X_{ii}X_{jj}}{X_{ij}X_{ji}}\right)^{\frac{1}{2(\sigma-1)}} - 1$$

**（2）产品差异化（ProdDiff）**

采用出口产品种类数的对数衡量

### 3.2.4 控制变量

| 变量 | 定义 |
|------|------|
| lnGDP_i | 出口省份GDP（对数） |
| lnGDP_j | 进口国GDP（对数） |
| lnDist | 双边地理距离（对数） |
| FTA | 是否签署自贸协定 |
| Language | 是否有共同语言 |
| Internet | 进口国互联网普及率 |
| Tariff | 行业平均关税率 |

## 3.3 模型设计

### 3.3.1 双重差分模型（DID）

$$Y_{ijkt} = \beta_0 + \beta_1 CBEC_{it} + \gamma Controls_{ijkt} + \mu_{ijk} + \lambda_t + \varepsilon_{ijkt}$$

其中：
- $Y_{ijkt}$：省份i对国家j行业k在t年的出口竞争力指标
- $CBEC_{it}$：省份i在t年是否设立跨境电商试验区
- $\mu_{ijk}$：省份-国家-行业固定效应
- $\lambda_t$：年份固定效应

### 3.3.2 多期DID模型

由于试验区分批设立（2015、2016、2018、2020、2022年），采用多期DID：

$$Y_{ijkt} = \beta_0 + \beta_1 Treat_i \times Post_t + \gamma Controls_{ijkt} + \mu_{ijk} + \lambda_t + \varepsilon_{ijkt}$$

### 3.3.3 中介效应模型

**第一步**：检验总效应
**第二步**：检验CBEC对中介变量的影响
**第三步**：同时纳入CBEC和中介变量

## 4.4 稳健性检验

### 4.4.1 安慰剂检验

随机分配跨境电商试验区设立时间和地点，重复1000次，构建伪处理效应分布。实际效应（0.172）显著高于95%的伪效应，排除随机因素干扰。

### 4.4.2 PSM-DID

采用倾向得分匹配（PSM）构建对照组，再进行DID分析。结果稳健（β=0.165, p<0.01）。

### 4.4.3 排除其他政策干扰

控制同期其他政策（自贸区设立、出口退税调整等），结果稳健。

# 第5章 研究结论与建议

## 5.1 研究结论

1. **跨境电商显著提升出口竞争力**：出口额平均提升18.5%，RCA指数提升0.12

2. **作用机制**：贸易成本降低（25.8%）和产品差异化（31.2%）是重要传导路径

3. **异质性效应**：东南亚国家和消费品行业的效应更显著

4. **结构优化**：跨境电商促进了高附加值产品出口

## 5.2 政策建议

### 对政府
1. **扩大试验区覆盖**：特别是中西部省份
2. **完善支持政策**：税收、通关、物流等
3. **推动标准对接**：与沿线国家对接规则标准

### 对企业
1. **积极拥抱跨境电商**：利用平台拓展市场
2. **注重产品差异化**：避免价格竞争
3. **建设海外仓**：提升物流效率

### 对行业协会
1. **搭建服务平台**：信息、培训、对接
2. **推动行业自律**：规范市场秩序
3. **促进经验分享**：推广成功案例

## 5.3 研究局限与展望

1. 跨境电商测度可进一步细化
2. 可探索更多作用机制
3. 可扩展至其他国家和地区
