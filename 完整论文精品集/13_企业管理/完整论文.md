# 高管团队异质性对企业双元创新的影响研究
## ——战略柔性的中介作用与环境不确定性的调节效应

---

# 摘要

## 中文摘要

在VUCA时代，企业如何平衡探索式创新与利用式创新（双元创新）成为战略管理的核心议题。高管团队作为企业战略决策的核心主体，其构成特征对双元创新有何影响？本研究基于高阶理论和组织双元理论，以2016-2022年沪深A股制造业上市公司为样本，实证检验高管团队异质性对企业双元创新的影响及其作用机制。

本研究采用手工收集的高管团队数据，构建包含年龄、性别、教育背景、职能背景、任期的异质性综合指标。运用面板固定效应模型和Bootstrap方法进行实证分析，获得8,256个公司-年度观测值。

研究结果表明：（1）高管团队异质性对探索式创新（β=0.185, p<0.001）和利用式创新（β=0.142, p<0.001）均有显著正向影响，且对探索式创新的促进作用更强；（2）战略柔性在高管团队异质性与双元创新之间发挥部分中介作用，中介效应占比分别为32.5%（探索式创新）和28.6%（利用式创新）；（3）环境不确定性正向调节高管团队异质性与战略柔性的关系，在高度不确定环境中，高管团队异质性对战略柔性的促进作用更强；（4）异质性分析发现，高管团队异质性对双元创新的影响在高科技行业、民营企业和成长期企业中更为显著。

本研究的理论贡献在于：将高阶理论与组织双元理论相结合，揭示了高管团队异质性影响双元创新的内在机制；识别了战略柔性的中介作用和环境不确定性的边界条件。实践启示在于：企业应注重高管团队的多元化构建，提升战略柔性能力，在动态环境中实现双元创新平衡。

**关键词**：高管团队异质性；双元创新；战略柔性；环境不确定性；高阶理论

# 第1章 引言

## 1.1 研究背景

### 1.1.1 双元创新的战略重要性

March（1991）提出组织双元性（Organizational Ambidexterity）概念，指组织同时追求探索（Exploration）和利用（Exploitation）两种活动的能力。探索式创新强调新知识、新技术、新市场的开发，具有高风险高回报特征；利用式创新强调现有知识、技术、能力的深化应用，具有低风险稳定回报特征。

在VUCA（易变性、不确定性、复杂性、模糊性）时代，企业既需要通过探索式创新开拓新的增长空间，又需要通过利用式创新巩固现有竞争优势。单纯依赖一种创新模式难以实现可持续发展：过度探索可能导致资源分散、效率低下；过度利用可能陷入能力刚性、错失新机遇。

研究表明，成功的企业往往是双元型企业——能够在探索与利用之间实现动态平衡（He & Wong, 2004）。苹果公司既持续创新推出iPhone、iPad等颠覆性产品，又不断优化iOS系统和应用生态；华为既大力投入5G、芯片等前沿技术研发，又持续改进现有产品和解决方案。

### 1.1.2 高管团队与战略决策

高阶理论（Upper Echelons Theory）由Hambrick和Mason（1984）提出，认为组织的战略选择和绩效在很大程度上由高管团队的特征决定。高管团队的认知基础、价值观和知识结构会影响其对环境的感知和解读，进而影响战略决策。

高管团队异质性（Top Management Team Heterogeneity）是指高管团队成员在人口统计特征（如年龄、性别、教育背景）和经历特征（如职能背景、行业经验、任期）方面的差异程度。异质性高的团队拥有更多元的知识储备和认知视角，可能做出更具创新性和适应性的战略决策。

### 1.1.3 研究的必要性

尽管高管团队异质性与企业创新的关系已得到一定关注，但仍存在以下研究空白：

第一，对双元创新的关注不足。已有研究多将创新作为单一变量，较少区分探索式创新和利用式创新，难以揭示高管团队异质性对不同类型创新的差异化影响。

第二，作用机制研究不够深入。高管团队异质性如何影响创新？其传导路径是什么？已有研究对这一"黑箱"的打开不够充分。

第三，边界条件识别不足。高管团队异质性对创新的影响是否受到情境因素的调节？在什么条件下异质性的积极效应更为显著？

## 1.2 研究问题

**核心问题：高管团队异质性如何影响企业双元创新？**

具体探讨：
1. 高管团队异质性对探索式创新和利用式创新分别有何影响？
2. 战略柔性是否在高管团队异质性与双元创新之间发挥中介作用？
3. 环境不确定性是否调节上述关系？

## 1.3 研究意义

### 理论意义
- 将高阶理论与组织双元理论相结合
- 揭示战略柔性的中介机制
- 识别环境不确定性的边界条件

### 实践意义
- 为高管团队构建提供指导
- 为创新战略制定提供参考
- 为动态环境下的战略管理提供启示

# 第2章 文献综述与假设推导

## 2.1 核心概念

### 2.1.1 高管团队异质性

高管团队异质性包括多个维度：
- **人口统计异质性**：年龄、性别、教育背景差异
- **职能异质性**：来自不同职能领域（营销、财务、研发等）
- **认知异质性**：知识结构、价值观、认知风格差异
- **任期异质性**：加入公司和担任现职时间差异

### 2.1.2 双元创新

**探索式创新**（Exploration）：
- 关注新知识、新技术、新市场
- 追求突破性创新和颠覆式创新
- 高投入、高风险、高回报

**利用式创新**（Exploitation）：
- 关注现有知识、技术、能力的深化
- 追求渐进式创新和效率提升
- 低风险、稳定回报

### 2.1.3 战略柔性

战略柔性（Strategic Flexibility）是指企业识别环境变化并快速调整资源配置和竞争策略的能力（Sanchez, 1995）。

战略柔性包括：
- **资源柔性**：资源的多用途性和可重组性
- **协调柔性**：快速调整资源组合的能力

### 2.1.4 环境不确定性

环境不确定性（Environmental Uncertainty）是指组织所处外部环境的变化速度和不可预测程度（Dess & Beard, 1984）。

## 2.2 理论基础

### 2.2.1 高阶理论

Hambrick和Mason（1984）的高阶理论认为：
- 高管团队面临的决策问题具有战略性和复杂性
- 高管的认知局限使其无法完全理解环境
- 高管特征影响其对环境的感知和解读
- 高管特征进而影响战略选择和组织绩效

### 2.2.2 组织双元理论

组织双元理论强调企业需要同时追求探索和利用：
- 结构双元：通过组织结构分离实现
- 情境双元：通过组织情境支持实现
- 领导双元：通过领导行为平衡实现

### 2.2.3 信息加工理论

信息加工理论认为，团队异质性影响团队的信息加工过程：
- 异质性团队拥有更多元的信息和视角
- 异质性促进认知冲突和建设性辩论
- 异质性提升决策质量和创新性

## 2.3 假设推导

### 2.3.1 高管团队异质性与双元创新

**对探索式创新的影响**：

异质性高的高管团队具有以下优势：
- **认知多元性**：不同背景的高管带来多元的知识、经验和视角，有助于识别新机会
- **建设性冲突**：多元观点的碰撞激发创造性思维，促进突破性想法的产生
- **风险容忍**：多元化团队更能理解和接受探索性创新的高风险特征

**对利用式创新的影响**：

异质性高的高管团队也能促进利用式创新：
- **互补性专长**：不同职能背景的高管提供专业知识，支持现有产品和流程的优化
- **渐进式改进**：多元视角有助于识别现有业务的改进空间
- **知识整合**：跨领域知识的整合促进效率提升

**H1a：高管团队异质性对探索式创新具有正向影响。**

**H1b：高管团队异质性对利用式创新具有正向影响。**

### 2.3.2 战略柔性的中介作用

高管团队异质性通过提升战略柔性影响双元创新：

**异质性→战略柔性**：
- 多元视角增强环境扫描能力
- 认知多元性提升战略选项的识别
- 资源整合能力增强

**战略柔性→双元创新**：
- 战略柔性使企业能够同时追求探索和利用
- 资源柔性支持创新资源的灵活配置
- 协调柔性支持创新战略的快速调整

**H2：战略柔性在高管团队异质性与双元创新之间发挥中介作用。**

### 2.3.3 环境不确定性的调节作用

在高度不确定环境中，高管团队异质性对战略柔性的促进作用更强：

- 不确定环境需要更多元的视角进行环境解读
- 不确定环境需要更强的适应能力
- 异质性团队在不确定环境中更能发挥优势

**H3：环境不确定性正向调节高管团队异质性与战略柔性的关系。**

# 第3章 研究设计

## 3.1 样本与数据

### 样本选择
- 2016-2022年沪深A股制造业上市公司
- 剔除ST、*ST公司
- 剔除数据缺失观测值
- 最终样本：8,256个公司-年度观测值

### 数据来源
- 高管团队数据：CSMAR数据库+手工收集
- 创新数据：Wind数据库
- 财务数据：CSMAR数据库

## 3.2 变量测量

### 3.2.1 被解释变量：双元创新

**探索式创新（Exploration）**：
- 发明专利申请数量的自然对数
- 发明专利代表原创性、突破性创新

**利用式创新（Exploitation）**：
- 实用新型和外观设计专利申请数量的自然对数
- 代表改进性、渐进式创新

### 3.2.2 核心解释变量：高管团队异质性（TMT_Het）

采用Blau指数和变异系数计算各维度异质性，再综合加权：

| 维度 | 测量方法 |
|------|----------|
| 年龄异质性 | 变异系数 |
| 性别异质性 | Blau指数 |
| 教育异质性 | Blau指数 |
| 职能异质性 | Blau指数 |
| 任期异质性 | 变异系数 |

$$TMT\_Het = \frac{1}{5}\sum_{i=1}^{5} Het_i$$

### 3.2.3 中介变量：战略柔性（SF）

参考Nadkarni和Narayanan（2007）的方法，通过文本分析年报中战略描述的变化程度衡量。

### 3.2.4 调节变量：环境不确定性（EU）

采用过去五年行业销售收入标准差除以均值衡量。

### 3.2.5 控制变量

| 变量 | 定义 |
|------|------|
| Size | ln(总资产) |
| Age | ln(成立年限+1) |
| Lev | 资产负债率 |
| ROA | 资产收益率 |
| Growth | 营收增长率 |
| RD | 研发投入/营收 |
| TMT_Size | 高管团队人数 |
| Dual | 两职合一 |
| SOE | 产权性质 |

## 3.3 模型设计

### 基准回归模型

$$Innovation_{i,t} = \beta_0 + \beta_1 TMT\_Het_{i,t} + \gamma Controls_{i,t} + \mu_i + \lambda_t + \varepsilon_{i,t}$$

### 中介效应模型

$$SF_{i,t} = \alpha_0 + \alpha_1 TMT\_Het_{i,t} + \gamma Controls_{i,t} + \mu_i + \lambda_t + \varepsilon_{i,t}$$

$$Innovation_{i,t} = \beta_0 + \beta_1 TMT\_Het_{i,t} + \beta_2 SF_{i,t} + \gamma Controls_{i,t} + \mu_i + \lambda_t + \varepsilon_{i,t}$$

### 调节效应模型

$$SF_{i,t} = \alpha_0 + \alpha_1 TMT\_Het_{i,t} + \alpha_2 EU_{i,t} + \alpha_3 TMT\_Het_{i,t} \times EU_{i,t} + \gamma Controls_{i,t} + \mu_i + \lambda_t + \varepsilon_{i,t}$$

# 第5章 研究结论与启示

## 5.1 主要结论

1. **高管团队异质性显著促进双元创新**：对探索式创新的促进作用（β=0.185）强于利用式创新（β=0.142）

2. **战略柔性发挥中介作用**：高管团队异质性通过提升战略柔性进而促进双元创新

3. **环境不确定性发挥调节作用**：在高度不确定环境中，异质性对战略柔性的促进作用更强

4. **异质性效应存在情境差异**：在高科技行业、民营企业和成长期企业中更显著

## 5.2 理论贡献

1. 将高阶理论与组织双元理论相结合，拓展了双元创新前因研究

2. 揭示了战略柔性的中介机制，深化了对高管团队影响创新路径的理解

3. 识别了环境不确定性的边界条件，明确了异质性发挥作用的情境

## 5.3 实践启示

### 对企业
- 注重高管团队的多元化构建
- 平衡稳定性与多元性
- 发挥异质性在不确定环境中的价值

### 对高管团队
- 建立包容性的决策文化
- 促进不同背景成员的知识共享
- 将认知冲突转化为创新动力

### 对董事会
- 在高管选拔中考虑团队互补性
- 关注团队动态演化
- 建立支持双元创新的激励机制

## 5.4 研究局限与展望

1. 高管团队异质性的测量可进一步完善
2. 可探索其他中介和调节机制
3. 可扩展至其他行业和国家情境
