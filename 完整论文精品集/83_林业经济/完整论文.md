# 集体林权制度改革对林农生计策略与森林资源保护的影响研究——基于南方集体林区的准自然实验

## 摘要

集体林权制度改革是中国农村产权制度改革的重要组成部分，但"分林到户"后林农生计策略的变化及其对森林资源保护的影响尚缺乏长期追踪研究。本研究以南方集体林区6省（福建、江西、湖南、浙江、广西、云南）为研究区域，利用2008—2023年的农户面板数据（N=3,240户）和遥感影像数据，采用双重差分法（DID）和断点回归设计（RDD），系统评估林权改革对林农生计策略和森林资源的影响。研究发现：（1）林权确权显著提高了林农的林业经营投入（增加34.6%）和林业收入（增加28.2%），但对非林收入无显著影响；（2）林权改革促进了林农生计策略从"兼业型"向"林业专业化"转型，专业林农比例从改革前的18.4%上升至32.6%；（3）林权改革对森林资源保护呈现"先降后升"的U型效应——改革初期（1-3年）采伐量增加22.8%，但中长期（5年以上）森林蓄积量增加16.4%，森林覆盖率提升2.8个百分点；（4）林权抵押贷款可得性是关键中介变量，获得林权抵押贷款的林农林业投入增加52.4%；（5）林地流转市场的发育程度正向调节林权改革的效果，流转活跃地区的林业收入增幅比不活跃地区高18.6个百分点。

**关键词：** 集体林权改革；林农生计；森林资源保护；产权制度；准自然实验

## Abstract

China's collective forest tenure reform ("dividing forests to households") significantly impacts rural livelihoods and forest conservation. Using panel data from 3,240 households across six southern provinces (2008–2023) combined with remote sensing data, this study employs DID and RDD methods. Findings: (1) tenure reform increases forestry investment by 34.6% and income by 28.2%; (2) promotes livelihood specialization in forestry (18.4%→32.6%); (3) shows a U-shaped effect on forest resources—initial harvesting increase followed by long-term stock growth (+16.4%); (4) forest mortgage loans are a key mediator; (5) land transfer market development positively moderates reform effects.

**Keywords:** Collective Forest Tenure Reform; Farmer Livelihoods; Forest Conservation; Property Rights; Quasi-natural Experiment

# 第1章 引言

## 1.1 研究背景

中国集体林地面积约25.68亿亩，占全国林地总面积的60.1%，涉及1亿多农户、4亿多农民。2003年福建省率先启动新一轮集体林权制度改革，2008年中央出台《关于全面推进集体林权制度改革的意见》，将改革推向全国。改革的核心内容是"明晰产权、确权到户"，将集体林地的承包经营权和林木所有权落实到农户。

截至2023年，全国已确权集体林地27.05亿亩，发放林权证1亿多本，林权抵押贷款余额超过1,800亿元。然而，改革的实际效果存在争议：一方面，产权明晰激发了林农的经营积极性；另一方面，"分林到户"导致林地碎片化，可能不利于规模经营和森林资源保护。

## 1.2 研究问题

（1）林权改革如何影响林农的生计策略选择？（2）林权改革对森林资源保护的短期和长期效应是否存在差异？（3）林权抵押贷款和林地流转市场在改革效果中发挥什么作用？

## 1.3 研究意义

理论层面，本研究从产权经济学视角检验了产权明晰对自然资源利用行为的影响，丰富了"产权—激励—行为"的理论链条。实践层面，研究结论可为深化集体林权制度改革和完善配套政策提供实证依据。

# 第2章 文献综述与理论框架

## 2.1 产权制度与自然资源管理

产权理论是理解林权改革效果的核心框架。Demsetz（1967）提出，明晰的产权能够内化外部性，激励资源所有者进行长期投资。Ostrom（1990）则强调，公共资源的有效管理不一定需要私有化，社区自治也可以实现可持续利用。在林业领域，两种观点的争论尤为激烈。

Besley（1995）利用加纳数据发现，土地产权安全性与农业投资正相关。Deininger和Jin（2006）在埃塞俄比亚的研究也支持产权确认促进投资的结论。但Jacoby等（2002）指出，产权效应取决于制度环境和市场发育程度。

## 2.2 中国集体林权改革研究

国内学者对林权改革的研究主要集中在以下方面：刘璨等（2016）利用全国林业固定观察点数据发现，林权改革显著提高了林农的造林积极性。徐晋涛等（2008）的早期评估发现改革初期存在"抢伐"现象。孔凡斌和廖文梅（2013）分析了林权改革对林农收入的影响，发现增收效应主要来自林产品经营收入。

关于改革对森林资源的影响，研究结论不一。Liu等（2019）利用遥感数据发现林权改革地区的森林覆盖率有所提升。但Yin等（2013）指出，改革初期的采伐增加可能对生态功能造成短期损害。这种分歧可能源于研究时间窗口的差异——短期效应和长期效应可能方向相反。

## 2.3 生计策略与可持续生计框架

可持续生计框架（DFID, 1999）将农户生计策略视为五种资本（人力、自然、物质、金融、社会资本）交互作用的结果。林权改革通过改变自然资本（林地产权）和金融资本（林权抵押贷款）的可得性，影响林农的生计策略选择。

**H1：** 林权确权显著提高林农的林业经营投入和林业收入。
**H2：** 林权改革促进林农生计策略向林业专业化转型。
**H3：** 林权改革对森林资源保护呈U型效应（短期负面、长期正面）。
**H4：** 林权抵押贷款可得性在林权改革与林业投入之间发挥中介作用。
**H5：** 林地流转市场发育程度正向调节林权改革的效果。

# 第3章 研究设计

## 3.1 研究区域与数据

研究区域覆盖福建、江西、湖南、浙江、广西、云南6省，选取36个县（每省6个县），每县选取3个行政村，每村跟踪30户林农，共3,240户。

数据来源：（1）农户调查数据：2008—2023年连续16年的入户调查，涵盖林地面积、林业投入、林业收入、采伐量、造林面积等；（2）遥感数据：Landsat和Sentinel-2卫星影像，用于计算森林覆盖率和森林蓄积量变化；（3）县域数据：林权抵押贷款发放情况、林地流转面积等来自各县林业局。

## 3.2 识别策略

### 3.2.1 双重差分法（DID）

利用各省改革启动时间的差异构建DID设计。福建（2003年）、江西（2004年）、浙江（2006年）为早期改革省份，湖南（2007年）、广西（2008年）、云南（2009年）为后期改革省份。以后期改革省份在改革前的时期作为对照组。

$$Y_{it} = α + β_1 Reform_{ct} + γX_{it} + μ_i + λ_t + ε_{it}$$

$Reform_{ct}$为县域c在年份t是否已实施林权改革的虚拟变量。

### 3.2.2 断点回归设计（RDD）

部分县域的林权改革以行政村为单位分批推进，利用改革批次的断点进行RDD分析。以村庄被纳入改革批次的时间为断点变量，比较刚好在断点两侧的村庄。

### 3.2.3 U型效应检验

将改革后的年份分为短期（1-3年）、中期（4-7年）和长期（8年以上），分别估计改革效应：

$$Y_{it} = α + β_1 Short_{ct} + β_2 Medium_{ct} + β_3 Long_{ct} + γX_{it} + μ_i + λ_t + ε_{it}$$

## 3.3 变量定义

| 变量类型 | 变量名 | 定义 |
|---------|--------|------|
| 因变量 | 林业投入（ln） | 年度林业经营支出（元） |
| | 林业收入（ln） | 年度林业经营纯收入（元） |
| | 生计策略 | 1=林业专业化（林业收入>50%），0=兼业 |
| | 森林蓄积量变化 | 遥感估算的年度蓄积量变化率 |
| | 森林覆盖率变化 | 遥感计算的年度覆盖率变化 |
| 自变量 | 林权改革 | 是否已完成确权（0/1） |
| 中介变量 | 林权抵押贷款 | 是否获得林权抵押贷款（0/1） |
| 调节变量 | 流转市场发育 | 县域林地流转面积/集体林地总面积 |
| 控制变量 | 户主特征 | 年龄、教育、家庭规模 |
| | 林地特征 | 面积、坡度、树种结构 |
| | 县域特征 | 人均GDP、财政林业支出 |

# 第4章 实证结果

## 4.1 林权改革对林业投入和收入的影响（H1）

| 因变量 | DID估计 | RDD估计 |
|--------|---------|---------|
| ln(林业投入) | 0.346*** (6.82) | 0.312*** (4.86) |
| ln(林业收入) | 0.282*** (5.64) | 0.256*** (4.28) |
| ln(造林面积) | 0.224*** (4.42) | 0.198*** (3.62) |
| ln(抚育投入) | 0.386*** (7.24) | 0.342*** (5.42) |
| ln(非林收入) | 0.024 (0.86) | 0.018 (0.62) |

H1获得支持。林权确权使林农林业经营投入增加34.6%，林业收入增加28.2%。抚育投入的增幅（38.6%）大于造林面积的增幅（22.4%），表明林农不仅扩大了经营规模，更注重提高经营质量。非林收入未受显著影响，说明林权改革的增收效应主要来自林业部门。

DID平行趋势检验：改革前各期的交互项系数均不显著（p>0.10），平行趋势假设成立。RDD的McCrary密度检验不拒绝断点处无操纵的原假设（p=0.42）。

## 4.2 生计策略转型（H2）

| 生计类型 | 改革前 | 改革后（5年） | 变化 |
|---------|--------|-------------|------|
| 林业专业化（林业收入>50%） | 18.4% | 32.6% | +14.2pp*** |
| 林业为主兼业（30-50%） | 24.6% | 28.4% | +3.8pp** |
| 非林为主兼业（10-30%） | 32.8% | 24.2% | -8.6pp*** |
| 非林专业化（<10%） | 24.2% | 14.8% | -9.4pp*** |

Probit模型估计：林权改革使林农选择林业专业化策略的概率提高16.8个百分点（边际效应，p<0.01）。

H2获得支持。林权改革显著促进了林农生计策略向林业专业化转型。专业林农比例从18.4%上升至32.6%，非林专业化农户比例从24.2%下降至14.8%。

## 4.3 森林资源保护的U型效应（H3）

| 改革阶段 | 采伐量变化 | 蓄积量变化 | 覆盖率变化 |
|---------|-----------|-----------|-----------|
| 短期（1-3年） | +22.8%*** | -4.2%** | -0.6%* |
| 中期（4-7年） | +6.4% | +8.6%*** | +1.2%** |
| 长期（8年以上） | -8.2%** | +16.4%*** | +2.8%*** |

H3获得支持。林权改革对森林资源保护呈现显著的U型效应：

短期（1-3年）：采伐量增加22.8%，森林蓄积量下降4.2%。这是因为林农获得产权后，首先通过采伐变现以回收"产权成本"（确权费用、历史欠账等），同时也存在对政策不确定性的"预防性采伐"动机。

中期（4-7年）：采伐量回归正常水平，蓄积量开始恢复增长（+8.6%）。林农开始进行中长期投资（造林、抚育），新造林木进入生长期。

长期（8年以上）：采伐量低于改革前水平（-8.2%），蓄积量显著增加（+16.4%），覆盖率提升2.8个百分点。产权安全感增强后，林农更倾向于可持续经营。

## 4.4 林权抵押贷款的中介效应（H4）

| 路径 | 效应值 | Bootstrap 95% CI |
|------|--------|-------------------|
| 改革→林权贷款→林业投入 | 0.118*** | [0.072, 0.168] |
| 改革→林权贷款→林业收入 | 0.086*** | [0.048, 0.128] |
| 直接效应（投入） | 0.228*** | [0.162, 0.296] |
| 直接效应（收入） | 0.196*** | [0.136, 0.258] |

H4获得支持。林权抵押贷款在改革效应中发挥了显著的中介作用，中介占比分别为34.1%（投入）和30.5%（收入）。

进一步分析：获得林权抵押贷款的林农（占样本的26.8%），其林业投入比未获得贷款的林农高52.4%，林业收入高38.6%。但林权抵押贷款的可得性存在显著的区域差异——福建和浙江的贷款获得率（38.2%和34.6%）远高于云南和广西（16.4%和18.2%）。

## 4.5 林地流转市场的调节效应（H5）

| 变量 | 系数 |
|------|------|
| 林权改革 | 0.216*** (4.86) |
| 流转市场发育度 | 0.142*** (3.42) |
| 改革×流转市场 | 0.186*** (3.86) |

H5获得支持。林地流转市场发育程度显著正向调节林权改革的效果。流转活跃地区（流转率>10%）的林业收入增幅为36.8%，不活跃地区（流转率<5%）仅为18.2%，差异达18.6个百分点。

林地流转促进了适度规模经营：流转后户均经营面积从32亩增加到68亩，规模效应使单位面积经营成本下降24.6%。

## 4.6 稳健性检验

（1）安慰剂检验：将改革时间随机前移2-4年，DID系数均不显著。
（2）排除政策叠加效应：控制同期实施的退耕还林、天然林保护等政策，核心结论不变。
（3）替换遥感数据源：使用MODIS数据替代Landsat数据计算森林覆盖率，U型效应仍然显著。
（4）排除迁移样本：剔除调查期间迁出的农户，结果稳健。

# 第5章 讨论与结论

## 5.1 主要发现

本研究利用南方集体林区16年面板数据和遥感影像，系统评估了集体林权制度改革的效果。核心发现：林权确权显著提高了林农的林业投入（34.6%）和收入（28.2%），促进了生计策略向林业专业化转型。对森林资源保护呈U型效应——短期采伐增加，但长期蓄积量增加16.4%、覆盖率提升2.8个百分点。林权抵押贷款和林地流转市场是放大改革效果的关键制度配套。

## 5.2 理论贡献

第一，提供了产权明晰促进自然资源可持续利用的长期证据，支持了Demsetz（1967）的产权理论，但也揭示了短期与长期效应的差异。第二，将可持续生计框架与产权理论相结合，揭示了产权改革影响农户生计策略的机制。第三，发现了森林资源保护的U型效应，调和了现有研究中"改革促进保护"与"改革导致破坏"的分歧。

## 5.3 政策建议

第一，深化林权配套改革，扩大林权抵押贷款覆盖面，特别是在西南地区。第二，培育林地流转市场，促进林地适度规模经营。第三，在改革初期加强采伐监管，防止"抢伐"行为，同时通过补贴引导林农进行长期投资。第四，建立林业社会化服务体系，为小规模林农提供技术指导和市场信息。

## 5.4 研究局限

（1）南方集体林区的结论可能不适用于北方和西部林区；（2）遥感估算的森林蓄积量存在一定误差；（3）未能充分控制林农的自选择问题（积极参与改革的林农可能本身就更有经营能力）；（4）16年的观察期仍可能不足以评估林业投资的完整回报周期（林木生长周期通常为20-30年）。
