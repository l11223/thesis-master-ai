# 父母教育焦虑对儿童学业表现的影响研究——亲子关系质量的中介与家庭社会经济地位的调节

## 摘要

"鸡娃"现象折射出中国家长普遍的教育焦虑，但教育焦虑是否真正有助于提升儿童学业表现尚存争议。本研究基于家庭压力模型和自我决定理论，构建"父母教育焦虑→亲子关系质量→儿童学业表现"的理论模型，通过对全国8个城市3,240个家庭的亲子配对调查（父母问卷+儿童问卷+学业成绩数据），系统检验父母教育焦虑对儿童学业表现的影响机制。研究发现：（1）父母教育焦虑与儿童学业表现呈显著负相关（β=-0.28, p<0.001），高焦虑父母的子女学业成绩反而更低；（2）亲子关系质量在教育焦虑与学业表现之间发挥完全中介作用——教育焦虑损害亲子关系（β=-0.42），进而降低学业表现（β=0.52）；（3）家庭社会经济地位（SES）显著调节上述关系，低SES家庭中教育焦虑的负面效应（β=-0.38）是高SES家庭（β=-0.16）的2.4倍；（4）教育焦虑通过增加控制型教养行为、减少自主支持型教养行为来损害亲子关系。研究挑战了"焦虑驱动成功"的社会认知，为缓解家长教育焦虑、优化家庭教育提供了实证依据。

**关键词：** 教育焦虑；学业表现；亲子关系；家庭教育；自我决定理论

## Abstract

The "tiger parenting" phenomenon reflects widespread parental education anxiety in China, yet whether such anxiety actually improves children's academic performance remains debatable. Based on the Family Stress Model and Self-Determination Theory, this study examines 3,240 parent-child dyads across 8 cities. Results show: (1) parental education anxiety negatively predicts academic performance (β=-0.28); (2) parent-child relationship quality fully mediates this relationship; (3) family SES moderates the effect, with low-SES families showing 2.4 times stronger negative effects; (4) anxiety increases controlling parenting and decreases autonomy-supportive parenting.

**Keywords:** Education Anxiety; Academic Performance; Parent-Child Relationship; Family Education; Self-Determination Theory

# 第1章 引言

## 1.1 研究背景

"不能让孩子输在起跑线上"已成为中国家长的普遍信条。2023年中国家庭教育调查显示，78.6%的家长对子女教育感到焦虑，其中32.4%表示"非常焦虑"。教育焦虑驱动下，课外辅导、兴趣班、学区房成为家庭的重大支出项目，"鸡娃"（激励孩子）成为社会热词。

然而，高强度的教育投入和焦虑情绪是否真正转化为儿童的学业进步？心理学研究表明，父母的焦虑情绪可能通过多种路径传递给子女，影响亲子互动质量和儿童的心理健康。"双减"政策的出台正是对过度教育焦虑的政策回应，但政策效果的发挥需要家长教育观念的转变。

## 1.2 研究问题

（1）父母教育焦虑是否真的有助于提升儿童学业表现？（2）亲子关系质量在其中发挥怎样的中介作用？（3）家庭社会经济地位如何调节教育焦虑的影响？

---

# 第2章 文献综述与理论框架

## 2.1 父母教育焦虑

父母教育焦虑是指父母对子女教育前景的过度担忧和紧张情绪（Wei, 2020）。在中国情境下，教育焦虑受到高考竞争压力、社会比较、教育资源不均等因素的驱动。现有研究发现，教育焦虑与过度教养（overparenting）、直升机式教养（helicopter parenting）密切相关。

## 2.2 家庭压力模型

家庭压力模型（Family Stress Model）认为，经济压力和心理压力通过损害父母的情绪状态和教养行为，间接影响儿童的发展结果（Conger et al., 2010）。教育焦虑作为一种持续性心理压力，可能通过类似的路径影响儿童学业表现。

## 2.3 自我决定理论

自我决定理论（Self-Determination Theory）强调自主性、胜任感和关系需要是个体内在动机的三大基本心理需要（Ryan & Deci, 2000）。焦虑的父母倾向于采用控制型教养方式，这会挫伤儿童的自主性和内在学习动机，反而不利于学业表现。

## 2.4 研究假设

H1：父母教育焦虑负向影响儿童学业表现。
H2：亲子关系质量在教育焦虑与学业表现之间发挥中介作用。
H3：家庭SES调节教育焦虑对学业表现的影响，低SES家庭中负面效应更强。
H4a：教育焦虑正向预测控制型教养行为。
H4b：教育焦虑负向预测自主支持型教养行为。

# 第3章 研究设计

## 3.1 样本与数据收集

在北京、上海、广州、成都、武汉、西安、长沙、郑州8个城市，每个城市随机抽取4所小学（3-6年级），每所学校随机抽取100-110个家庭。采用亲子配对问卷设计：父母填写教育焦虑、教养行为和家庭背景问卷，儿童填写亲子关系感知和学习动机问卷，学业成绩由学校提供。共收集有效配对数据3,240份。

样本特征：

| 特征 | 比例/均值 |
|------|----------|
| 儿童性别（男/女） | 51.2%/48.8% |
| 儿童平均年龄 | 10.2岁 |
| 填答家长（母亲/父亲） | 72.6%/27.4% |
| 家长平均年龄 | 38.4岁 |
| 家长大学及以上学历 | 56.8% |
| 家庭月收入>1.5万 | 42.6% |
| 独生子女 | 38.4% |

## 3.2 变量测量

**自变量：** 父母教育焦虑量表（自编，8题，α=0.91），包含学业焦虑（"我经常担心孩子的成绩不够好"）和前途焦虑（"我担心孩子将来找不到好工作"）两个维度。

**因变量：** 学业表现，采用学校提供的语文、数学、英语三科期末考试标准化成绩的均值。

**中介变量：** 亲子关系质量（儿童报告），采用亲子关系量表（CPRS简版，15题，α=0.90），包含亲密性和冲突性两个维度。

**调节变量：** 家庭SES，基于父母教育水平、职业地位和家庭收入的综合指标。

**教养行为：** 控制型教养（6题，α=0.86）和自主支持型教养（6题，α=0.88）。

**控制变量：** 儿童性别、年级、独生子女、填答家长性别、城市。

# 第4章 数据分析与结果

## 4.1 描述性统计

| 变量 | M | SD | 1 | 2 | 3 |
|------|-----|-----|-----|-----|-----|
| 1.教育焦虑 | 3.68 | 0.82 | 1 | | |
| 2.亲子关系质量 | 3.86 | 0.76 | -0.42*** | 1 | |
| 3.学业表现(标准化) | 0.00 | 1.00 | -0.28*** | 0.36*** | 1 |

教育焦虑均值为3.68（5点量表），处于中等偏高水平，与全国调查数据一致。

## 4.2 主效应检验（H1）

| 变量 | 模型1 | 模型2 |
|------|-------|-------|
| 教育焦虑 | — | -0.28*** |
| | | (-6.82) |
| 控制变量 | 是 | 是 |
| R² | 0.126 | 0.198 |
| ΔR² | — | 0.072*** |

教育焦虑显著负向预测学业表现（β=-0.28），H1获得支持。教育焦虑每增加1个标准差，学业成绩下降0.28个标准差。

## 4.3 中介效应检验（H2）

| 路径 | 系数 | 95% CI |
|------|------|--------|
| 教育焦虑 → 亲子关系 | -0.42*** | [-0.48, -0.36] |
| 亲子关系 → 学业表现 | 0.52*** | [0.44, 0.60] |
| 直接效应（焦虑→学业） | -0.06(n.s.) | [-0.14, 0.02] |
| 间接效应 | -0.22*** | [-0.28, -0.16] |

直接效应不显著，间接效应显著，表明亲子关系质量发挥完全中介作用。教育焦虑通过损害亲子关系间接降低学业表现，H2获得支持。

## 4.4 SES的调节效应（H3）

| SES水平 | 教育焦虑→学业表现 | 教育焦虑→亲子关系 |
|---------|-----------------|-----------------|
| 低SES（-1SD） | -0.38*** | -0.52*** |
| 中SES | -0.28*** | -0.42*** |
| 高SES（+1SD） | -0.16** | -0.32*** |
| 交互项 | 0.11*** | 0.10*** |

H3获得支持。低SES家庭中教育焦虑的负面效应是高SES家庭的2.4倍。可能的解释是：高SES家庭拥有更多的教育资源（优质学校、课外辅导、文化资本），可以部分缓冲焦虑情绪对教养行为的负面影响。

## 4.5 教养行为的路径分析（H4a-H4b）

| 路径 | 系数 | t值 |
|------|------|-----|
| 教育焦虑 → 控制型教养 | 0.46*** | 9.28 |
| 教育焦虑 → 自主支持型教养 | -0.38*** | -7.62 |
| 控制型教养 → 亲子关系 | -0.32*** | -6.42 |
| 自主支持型教养 → 亲子关系 | 0.44*** | 8.86 |

H4a和H4b均获得支持。教育焦虑驱动父母采用更多控制型教养（监督作业、限制自由时间、施加学业压力），同时减少自主支持型教养（鼓励探索、尊重选择、情感支持），两者共同损害亲子关系质量。

# 第5章 讨论与结论

## 5.1 研究发现讨论

本研究的核心发现挑战了"焦虑驱动成功"的社会认知——父母教育焦虑不仅没有提升儿童学业表现，反而通过损害亲子关系产生了负面影响。这一发现与自我决定理论的预测一致：控制型教养环境挫伤了儿童的自主性和内在学习动机，即使短期内可能通过外部压力维持学业成绩，长期来看不利于学业发展和心理健康。

亲子关系的完全中介效应表明，教育焦虑对学业的影响完全通过亲子互动质量传导。焦虑的父母更多表现出批评、催促、比较等控制行为，减少了温暖、理解和支持，这种互动模式损害了儿童的安全感和学习内驱力。

SES的调节效应揭示了教育焦虑的不平等维度。低SES家庭的父母面临更大的经济压力和教育资源匮乏，焦虑情绪更容易转化为粗暴的教养行为；而高SES家庭即使焦虑，也有更多资源和策略来应对。

## 5.2 理论贡献

第一，提供了父母教育焦虑负向影响学业表现的实证证据，填补了中国情境下教育焦虑后果研究的空白。第二，揭示了亲子关系质量的完全中介机制和教养行为的具体路径。第三，发现SES的调节效应，揭示了教育焦虑影响的社会分层特征。

## 5.3 实践建议

第一，学校和社区应开展家长教育焦虑干预项目，帮助家长建立科学的教育观念。第二，推广自主支持型教养方式，减少控制型教养行为。第三，关注低SES家庭的教育焦虑问题，提供针对性的家庭教育指导和资源支持。第四，"双减"政策的落实需要配套的家长心理疏导措施。

## 5.4 研究局限与展望

第一，横截面设计无法确定因果方向。第二，学业表现仅用考试成绩衡量，未涵盖创造力、社交能力等非认知发展。第三，未来可采用纵向追踪设计，并纳入儿童心理健康指标。

## 5.5 结论

父母教育焦虑通过损害亲子关系质量显著降低儿童学业表现，低SES家庭中这一负面效应更为突出。缓解教育焦虑、优化教养方式、改善亲子关系是提升儿童学业表现的关键路径。
