# 安全氛围感知对建筑工人不安全行为的影响机制研究——基于计划行为理论的扩展模型

## 摘要

建筑业是安全事故高发行业，工人不安全行为是事故发生的首要原因。本研究基于计划行为理论（TPB）构建扩展模型，通过对全国12个城市86个建筑工地的实地调查（N=2,480名建筑工人），检验安全氛围感知对不安全行为的影响机制。研究发现：（1）安全氛围感知显著负向影响不安全行为（β=-0.48，p<0.001），其中管理层安全承诺（β=-0.42）和安全沟通（β=-0.38）的影响最大；（2）安全态度（β=-0.36）、主观规范（β=-0.28）和感知行为控制（β=-0.32）在安全氛围与不安全行为之间发挥链式中介作用，中介效应占总效应的56.4%；（3）安全知识水平正向调节安全氛围对安全态度的影响（β=0.22），高安全知识工人对安全氛围的响应更积极；（4）工作压力负向调节安全态度对不安全行为的影响（β=0.18），高工作压力削弱了安全态度的行为约束力；（5）工龄呈U型调节效应——新手工人（<1年）和老手工人（>10年）的不安全行为发生率均高于中等工龄工人（3-7年），但原因不同：新手缺乏经验，老手过度自信。

**关键词：** 安全氛围；不安全行为；计划行为理论；建筑工人；安全管理

## Abstract

Construction workers' unsafe behaviors are the primary cause of workplace accidents. Extending the Theory of Planned Behavior, this study surveys 2,480 workers across 86 construction sites in 12 cities. Findings: (1) safety climate significantly reduces unsafe behaviors (β=-0.48); (2) safety attitude, subjective norms, and perceived behavioral control chain-mediate (56.4%); (3) safety knowledge positively moderates climate-attitude link; (4) work pressure negatively moderates attitude-behavior link; (5) work experience shows a U-shaped moderation—both novice (<1 year) and veteran (>10 years) workers exhibit more unsafe behaviors.

**Keywords:** Safety Climate; Unsafe Behavior; Theory of Planned Behavior; Construction Workers; Safety Management

# 第1章 引言

## 1.1 研究背景

建筑业是全球安全事故最严重的行业之一。2023年中国建筑业发生生产安全事故3,862起，死亡4,028人，分别占工矿商贸事故总量的32.6%和36.8%。Heinrich（1931）的事故因果连锁理论指出，88%的事故由人的不安全行为引起。近年来的研究也证实，建筑工人的不安全行为（如未佩戴安全帽、高处作业未系安全带、违规操作等）是事故发生的首要直接原因。

安全氛围（Safety Climate）被认为是影响工人安全行为的关键组织因素。Zohar（1980）首次提出安全氛围概念，将其定义为员工对组织安全政策、程序和实践的共享感知。大量研究证实安全氛围与安全行为正相关，但其影响机制——特别是在中国建筑业情境下——尚需深入探讨。

## 1.2 研究问题

（1）安全氛围感知如何通过认知和动机路径影响建筑工人的不安全行为？（2）安全知识和工作压力如何调节这一影响过程？（3）工龄对不安全行为的影响是否存在非线性特征？

## 1.3 研究贡献

第一，将TPB理论与安全氛围研究相结合，构建了"安全氛围—认知—行为"的整合模型。第二，发现了工作压力对安全态度—行为关系的削弱效应，揭示了"知行不一"的心理机制。第三，发现了工龄的U型调节效应，为差异化安全培训提供了依据。

# 第2章 文献综述与理论框架

## 2.1 安全氛围

安全氛围研究始于Zohar（1980）的开创性工作。Flin等（2000）的综述将安全氛围的核心维度归纳为：管理层承诺、安全系统与程序、安全沟通、工人参与和安全培训。Neal和Griffin（2006）提出安全氛围通过安全动机影响安全行为的理论模型。

在建筑业情境下，Mohamed（2002）开发了建筑业安全氛围量表。Choudhry等（2009）发现中国建筑工地的安全氛围受项目管理模式和分包体制的显著影响。周晓宏等（2018）利用中国建筑工人数据验证了安全氛围对安全行为的正向影响。

## 2.2 计划行为理论

Ajzen（1991）的计划行为理论认为，行为意向是行为的最直接预测因素，而行为意向受三个因素影响：态度（对行为的评价）、主观规范（感知到的社会压力）和感知行为控制（对执行行为难易程度的感知）。

TPB已被广泛应用于安全行为研究。Fogarty和Shaw（2010）利用TPB预测航空维修人员的违规行为。Fugas等（2012）将安全氛围作为TPB的前因变量，发现安全氛围通过影响安全态度和主观规范间接影响安全行为。

## 2.3 研究假设

**H1：** 安全氛围感知显著负向影响不安全行为。
**H2：** 安全态度、主观规范和感知行为控制在安全氛围与不安全行为之间发挥中介作用。
**H3：** 安全知识正向调节安全氛围对安全态度的影响。
**H4：** 工作压力负向调节安全态度对不安全行为的影响。
**H5：** 工龄对不安全行为呈U型影响。

# 第3章 研究设计

## 3.1 样本与数据收集

在北京、上海、广州、深圳、成都、武汉、西安、沈阳、济南、郑州、长沙、昆明12个城市，选取86个在建建筑工地（住宅工程42个、商业工程28个、基础设施工程16个），对一线建筑工人进行问卷调查。每个工地随机抽取25-35名工人，共发放2,800份问卷，回收有效问卷2,480份（有效率88.6%）。

样本特征：男性96.2%，平均年龄38.4岁，初中及以下学历62.8%，高中/中专28.4%，大专及以上8.8%。工种分布：钢筋工22.4%，木工18.6%，混凝土工16.2%，架子工14.8%，电焊工12.4%，其他15.6%。平均工龄8.6年。

## 3.2 变量测量

（1）**安全氛围**（20题，α=0.924）：改编自Mohamed（2002）和Fang等（2006），包含管理层安全承诺（5题）、安全规章制度（4题）、安全沟通（4题）、安全培训（4题）和工人安全参与（3题）五个维度。

（2）**安全态度**（6题，α=0.886）：改编自Rundmo（2000），测量工人对安全规程和安全行为的态度。

（3）**主观规范**（5题，α=0.862）：测量工人感知到的来自管理者、同事和家人的安全行为期望。

（4）**感知行为控制**（5题，α=0.874）：测量工人对执行安全行为的能力和条件的感知。

（5）**不安全行为**（12题，α=0.908）：改编自Choudhry和Fang（2008），测量过去一个月内不安全行为的发生频率（1=从不，5=经常），包括个人防护装备使用、操作规程遵守、安全警示忽视等。

（6）**安全知识**（8题，α=0.842）：测量工人对安全规程、危险源识别和应急处置的知识水平。

（7）**工作压力**（6题，α=0.868）：测量工期压力、工作强度和经济压力。

## 3.3 分析方法

采用Mplus 8.6进行结构方程模型分析，Bootstrap法（5000次）检验中介效应，多组分析和潜在调节结构方程（LMS）检验调节效应。

# 第4章 实证结果

## 4.1 测量模型

CFA模型拟合：χ²/df=2.12，CFI=0.938，TLI=0.932，RMSEA=0.046，SRMR=0.042。所有因子载荷>0.65，AVE>0.50，CR>0.85，测量模型质量良好。

各变量描述性统计与相关系数：

| 变量 | 均值 | SD | 1 | 2 | 3 | 4 | 5 | 6 |
|------|------|-----|---|---|---|---|---|---|
| 1.安全氛围 | 4.28 | 1.12 | — | | | | | |
| 2.安全态度 | 4.86 | 0.96 | .52** | — | | | | |
| 3.主观规范 | 4.42 | 1.08 | .46** | .48** | — | | | |
| 4.感知行为控制 | 4.16 | 1.14 | .42** | .44** | .38** | — | | |
| 5.不安全行为 | 2.24 | 0.86 | -.48** | -.42** | -.36** | -.38** | — | |
| 6.安全知识 | 4.62 | 1.06 | .38** | .46** | .32** | .42** | -.34** | — |

## 4.2 结构模型与直接效应（H1）

| 路径 | 标准化系数 | t值 |
|------|-----------|-----|
| 安全氛围→不安全行为（总效应） | -0.48*** | -8.86 |
| 管理层承诺→不安全行为 | -0.42*** | -7.62 |
| 安全沟通→不安全行为 | -0.38*** | -6.84 |
| 安全培训→不安全行为 | -0.34*** | -6.24 |
| 安全规章→不安全行为 | -0.30*** | -5.62 |
| 工人参与→不安全行为 | -0.28*** | -5.12 |

H1获得支持。安全氛围感知每提升1个标准差，不安全行为降低0.48个标准差。管理层安全承诺的影响最大（β=-0.42），表明"领导重视安全"是工人安全行为的最强信号。安全沟通（β=-0.38）排名第二，畅通的安全信息传递有助于工人识别和规避风险。

## 4.3 中介效应（H2）

| 中介路径 | 间接效应 | Bootstrap 95% CI |
|---------|---------|-------------------|
| 氛围→态度→行为 | -0.126*** | [-0.168, -0.088] |
| 氛围→规范→行为 | -0.068*** | [-0.098, -0.042] |
| 氛围→控制→行为 | -0.076*** | [-0.108, -0.048] |
| 总间接效应 | -0.270*** | [-0.326, -0.218] |
| 直接效应 | -0.210*** | [-0.276, -0.148] |
| 中介占比 | 56.4% | — |

H2获得支持。三个TPB变量共同中介了安全氛围对不安全行为56.4%的影响。安全态度是最重要的中介变量（间接效应-0.126），表明安全氛围主要通过改变工人对安全的态度来减少不安全行为。

链式中介路径也显著：氛围→态度→意向→行为（间接效应=-0.086，95% CI [-0.118, -0.058]），表明安全氛围通过塑造态度、形成行为意向、最终改变行为的完整认知链条。

## 4.4 安全知识的调节效应（H3）

| 安全知识水平 | 氛围→态度路径系数 |
|------------|-----------------|
| 低（下1/3） | 0.38*** |
| 中（中1/3） | 0.52*** |
| 高（上1/3） | 0.64*** |
| 调节效应 | 0.22*** (t=4.12) |

H3获得支持。安全知识正向调节安全氛围对安全态度的影响。高安全知识工人能够更好地理解安全氛围传递的信号，将组织的安全重视转化为个人的安全态度。低安全知识工人即使感知到良好的安全氛围，也可能因为不理解安全规程的重要性而态度转变有限。

## 4.5 工作压力的调节效应（H4）

| 工作压力水平 | 态度→行为路径系数 |
|------------|-----------------|
| 低（下1/3） | -0.46*** |
| 中（中1/3） | -0.36*** |
| 高（上1/3） | -0.22*** |
| 调节效应 | 0.18*** (t=3.42) |

H4获得支持。工作压力显著削弱了安全态度对不安全行为的约束力。在低工作压力条件下，安全态度对行为的影响为-0.46；在高工作压力条件下降至-0.22。这解释了"知行不一"现象——工人虽然知道应该遵守安全规程（态度积极），但在工期紧张、工作强度大的情况下，仍可能为了赶进度而采取不安全行为。

具体来看，工期压力（β=0.14）和经济压力（β=0.12）的调节效应最显著。计件工资制度下的工人不安全行为发生率比月薪制工人高34.6%。

## 4.6 工龄的U型效应（H5）

| 工龄段 | 不安全行为均值 | 与3-7年组的差异 |
|--------|-------------|----------------|
| <1年 | 2.68 | +0.52*** |
| 1-3年 | 2.32 | +0.16* |
| 3-5年 | 2.16 | 基准组 |
| 5-7年 | 2.18 | +0.02 |
| 7-10年 | 2.28 | +0.12* |
| >10年 | 2.56 | +0.40*** |

回归分析中，工龄的一次项系数为负（β=-0.18***），二次项系数为正（β=0.12***），证实U型关系。拐点约在6.2年。

H5获得支持。新手工人（<1年）不安全行为发生率最高（均值2.68），主要原因是缺乏经验和安全知识不足。3-7年工龄的工人不安全行为最少（均值2.16-2.18），经验积累和安全意识达到最佳平衡。10年以上老手工人的不安全行为回升（均值2.56），访谈发现主要原因是"过度自信"——认为自己经验丰富不会出事，从而放松了安全防护。

## 4.7 稳健性检验

（1）共同方法偏差：未测量的潜在方法因子法（ULMC）显示方法因子解释方差仅为3.8%。
（2）多层次分析：考虑工人嵌套在工地中的层次结构，采用HLM分析，核心结论不变。
（3）替换因变量：以安全行为观察记录（由安全员填写）替代自评不安全行为，安全氛围的效应仍然显著（β=-0.38***）。
（4）排除极端工地：剔除安全氛围得分最高和最低各5%的工地，结果稳健。

# 第5章 讨论与结论

## 5.1 主要发现

本研究基于2,480名建筑工人的调查数据，系统检验了安全氛围对不安全行为的影响机制。核心发现：安全氛围显著减少不安全行为（β=-0.48），管理层承诺和安全沟通是最关键的氛围维度；TPB三变量中介了56.4%的效应；安全知识增强氛围效果，工作压力削弱态度约束力；工龄呈U型效应，新手和老手均需重点关注。

## 5.2 理论贡献

第一，将安全氛围理论与TPB相整合，构建了"氛围—认知—行为"的完整理论链条。第二，发现了工作压力对"态度—行为"关系的削弱效应，揭示了安全管理中"知行不一"的心理机制。第三，发现了工龄的U型效应及其差异化原因，丰富了对建筑工人安全行为发展轨迹的理解。

## 5.3 实践建议

第一，强化管理层安全承诺的可见性——管理者应定期参加安全巡查、安全会议，让工人切实感受到"领导重视安全"。第二，建立畅通的安全沟通渠道，鼓励工人报告安全隐患而非惩罚。第三，针对不同工龄工人实施差异化安全培训：新手侧重安全知识和技能，老手侧重安全意识唤醒和案例警示。第四，合理安排工期和工作强度，避免工作压力过大导致安全行为退化。第五，改革计件工资制度，将安全绩效纳入薪酬考核。

## 5.4 研究局限

（1）截面调查设计无法确立严格的因果关系；（2）不安全行为主要依赖自评，可能存在社会期望偏差；（3）样本以男性为主（96.2%），对女性建筑工人的适用性有限；（4）未考虑项目类型和分包层级对安全氛围的影响。
