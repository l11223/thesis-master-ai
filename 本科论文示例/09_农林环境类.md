## 📝 农林类论文注意事项

### 数据记录要求
```
1. 详细记录试验时间
2. 记录气象数据
3. 保留原始数据
4. 统计分析规范
```

### 常用统计软件
```
SPSS、DPS、SAS、R语言
多重比较：Duncan、LSD
相关分析、回归分析
主成分分析、聚类分析
```
