# 示例1：护理学

## 基本信息

| 项目 | 内容 |
|------|------|
| 学科 | 护理学 |
| 类型 | 本科毕业论文 |
| 方法 | 问卷调查 |
| 字数 | 1.2万字 |

## 论文题目

**临床护士职业倦怠与离职意愿的相关性研究**

## 研究模型

```
┌─────────────┐         ┌─────────────┐         ┌─────────────┐
│  职业倦怠   │ ──────→ │  工作满意度  │ ──────→ │  离职意愿   │
│ - 情感耗竭  │   H1    │             │   H2    │             │
│ - 去人格化  │         └─────────────┘         └─────────────┘
│ - 成就感低  │                                        ▲
└─────────────┘                   H3                   │
        │                                              │
        └──────────────────────────────────────────────┘
```

## 研究假设

- H1：职业倦怠对工作满意度有显著负向影响
- H2：工作满意度对离职意愿有显著负向影响
- H3：职业倦怠对离职意愿有显著正向影响
- H4：工作满意度在职业倦怠与离职意愿之间起中介作用

## 论文大纲

### 第1章 绪论（1500字）
1.1 研究背景
1.2 研究目的与意义
1.3 研究方法

### 第2章 文献综述（2500字）
2.1 职业倦怠研究
2.2 离职意愿研究
2.3 两者关系研究
2.4 护理人员相关研究

### 第3章 研究方法（2000字）
3.1 研究对象
3.2 研究工具
- 马斯拉赫职业倦怠量表（MBI）
- 明尼苏达满意度量表
- 离职意愿量表
3.3 数据收集
3.4 统计方法

### 第4章 研究结果（3500字）
4.1 一般资料
4.2 职业倦怠现状
4.3 离职意愿现状
4.4 相关性分析
4.5 回归分析

### 第5章 讨论（2000字）
5.1 职业倦怠水平分析
5.2 影响因素讨论
5.3 护理管理建议

### 第6章 结论（1000字）

## 📝 医学论文注意事项

### 伦理审查
```
凡涉及人体研究需说明：
1. 伦理委员会审批
2. 知情同意书签署
3. 患者隐私保护
```
