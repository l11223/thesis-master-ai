# 包容型领导对员工敬业度的跨层次影响研究
## ——心理安全感的中介作用与团队异质性的调节效应

---

# 摘要

在多元化职场背景下，包容型领导日益受到关注。包容型领导如何影响员工敬业度？其作用机制是什么？团队特征如何影响这一关系？本研究基于社会信息加工理论，采用多层线性模型（HLM）方法，检验包容型领导对员工敬业度的跨层次影响机制。

研究以15家科技企业68个工作团队的425名员工为样本，采用团队层面领导问卷和个体层面员工问卷分两次收集数据。运用HLM 7.0进行跨层次分析。

研究结果表明：（1）包容型领导对员工心理安全感具有显著正向跨层次影响（γ=0.35, p<0.001）；（2）心理安全感对员工敬业度具有显著正向影响（β=0.42, p<0.001）；（3）心理安全感在包容型领导与员工敬业度之间起跨层次中介作用，间接效应为0.15（95% CI=[0.08, 0.24]）；（4）团队异质性正向调节包容型领导与心理安全感的关系（γ=0.18, p<0.05），在高异质性团队中，包容型领导对心理安全感的促进作用更强。

**关键词**：包容型领导；员工敬业度；心理安全感；跨层次分析；多层线性模型

# 第1章 引言

## 1.1 研究背景

### 1.1.1 员工敬业度的战略重要性
员工敬业度是组织竞争力的重要来源。盖洛普调查显示，高敬业度组织的生产率比低敬业度组织高21%，利润率高22%。

### 1.1.2 职场多元化趋势
全球化和人口结构变化使职场日益多元化。如何管理多元化团队、发挥不同员工的潜力，成为重要管理课题。

### 1.1.3 包容型领导的兴起
包容型领导（Inclusive Leadership）强调尊重差异、开放接纳、促进参与，被认为是应对多元化挑战的有效领导方式（Nembhard & Edmondson, 2006）。

## 1.2 问题提出

1. 包容型领导是否能够提升员工敬业度？
2. 心理安全感是否是包容型领导发挥作用的中介机制？
3. 团队异质性是否调节上述关系？

## 1.3 研究方法选择

### 为什么采用多层线性模型？
- 数据具有嵌套结构：员工（Level-1）嵌套于团队（Level-2）
- 违反独立性假设：同一团队员工可能存在相关性
- 需要同时分析不同层次变量的效应

# 第2章 文献综述与假设推导

## 2.1 包容型领导

### 概念界定
包容型领导是指领导者展现出开放、可得和易接近的行为，邀请和欣赏他人的贡献（Carmeli et al., 2010）。

### 核心特征
- **开放性（Openness）**：愿意倾听不同意见
- **可得性（Availability）**：在员工需要时能够提供支持
- **易接近性（Accessibility）**：降低与员工的心理距离

### 与其他领导风格的区分
| 领导风格 | 核心焦点 | 与包容型领导的区别 |
|----------|----------|-------------------|
| 变革型领导 | 愿景激励 | 包容型更强调接纳差异 |
| 服务型领导 | 服务他人 | 包容型更强调促进参与 |
| 授权型领导 | 权力下放 | 包容型更强调开放接纳 |

## 2.2 员工敬业度

### 概念界定
员工敬业度是指员工在工作角色中投入的身体、认知和情感能量（Kahn, 1990）。

### 三维度模型
- **活力（Vigor）**：工作中的精力和心理韧性
- **奉献（Dedication）**：对工作的热情、自豪和挑战感
- **专注（Absorption）**：全身心投入工作的状态

### 测量工具
UWES（Utrecht Work Engagement Scale）是最常用的敬业度量表（Schaufeli et al., 2002）。

## 2.3 心理安全感

### 概念界定
心理安全感是指个体对承担人际风险后果的感知，即相信在团队中表达自己不会受到惩罚或嘲笑（Edmondson, 1999）。

### 重要性
心理安全感使员工敢于：
- 提出问题和想法
- 承认错误
- 寻求反馈和帮助
- 尝试新方法

## 2.4 团队异质性

### 概念界定
团队异质性是指团队成员在人口统计特征、职能背景、价值观等方面的差异程度。

### 异质性的双刃剑效应
- **正面效应**：多元视角、创新潜力
- **负面效应**：沟通障碍、冲突风险

## 2.5 理论基础与假设推导

### 社会信息加工理论
员工通过观察和解读工作环境中的信息（包括领导行为）来形成对工作的态度和行为（Salancik & Pfeffer, 1978）。

### 假设推导

**H1**：包容型领导对员工心理安全感具有显著正向跨层次影响

包容型领导展现的开放、接纳和支持行为，向员工传递了"表达自己是安全的"信号，从而增强员工的心理安全感。

**H2**：心理安全感对员工敬业度具有显著正向影响

心理安全感使员工敢于全身心投入工作，愿意承担风险、尝试新方法，从而表现出更高的敬业度。

**H3**：心理安全感在包容型领导与员工敬业度之间起跨层次中介作用

包容型领导通过增强员工心理安全感，进而提升员工敬业度。

**H4**：团队异质性正向调节包容型领导与心理安全感的关系

在高异质性团队中，成员面临更多差异和潜在冲突，更需要包容型领导的接纳和支持来建立心理安全感。

# 第3章 研究设计

## 3.1 样本与数据收集

### 样本选择
- 企业：15家科技企业（北京、上海、深圳）
- 团队：68个工作团队
- 员工：425名员工
- 行业：软件开发、互联网、人工智能

### 数据收集程序
**时点1**（T1）：发放领导问卷和员工问卷第一部分
- 领导填写：团队异质性感知
- 员工填写：包容型领导感知、人口统计变量

**时点2**（T2，间隔2周）：发放员工问卷第二部分
- 员工填写：心理安全感、敬业度

### 样本特征

**团队层面（N=68）**
| 特征 | 均值 | 标准差 |
|------|------|--------|
| 团队规模 | 6.3人 | 2.1 |
| 团队年龄 | 2.8年 | 1.5 |

**个体层面（N=425）**
| 特征 | 类别 | 百分比 |
|------|------|--------|
| 性别 | 男 | 58.4% |
| | 女 | 41.6% |
| 年龄 | 25岁以下 | 18.2% |
| | 25-35岁 | 55.8% |
| | 35岁以上 | 26.0% |
| 学历 | 本科 | 62.5% |
| | 硕士及以上 | 37.5% |
| 工龄 | 3年以下 | 35.2% |
| | 3-10年 | 48.6% |
| | 10年以上 | 16.2% |

## 3.2 变量测量

### 包容型领导（团队聚合到L2）
- 量表：Carmeli et al.（2010），9题项
- 来源：员工评价→聚合到团队层面
- 信度：α=0.92

### 心理安全感（L1）
- 量表：Edmondson（1999），7题项
- 信度：α=0.88

### 员工敬业度（L1）
- 量表：UWES-9（Schaufeli et al., 2002）
- 维度：活力、奉献、专注
- 信度：α=0.91

### 团队异质性（L2）
- 测量：年龄、教育背景、职能背景的标准差
- 计算：综合异质性指数

### 控制变量
- L1：性别、年龄、学历、工龄
- L2：团队规模、团队年龄

## 3.3 数据聚合检验

包容型领导需要从个体感知聚合到团队层面：

| 指标 | 数值 | 标准 | 结论 |
|------|------|------|------|
| rwg均值 | 0.85 | >0.7 | ✓通过 |
| ICC(1) | 0.18 | >0.05 | ✓通过 |
| ICC(2) | 0.72 | >0.7 | ✓通过 |

支持将包容型领导聚合到团队层面。

## 3.4 分析策略

采用HLM 7.0进行多层线性模型分析：

**零模型**：检验是否需要HLM
$$Y_{ij} = \gamma_{00} + u_{0j} + r_{ij}$$

**随机截距模型**：检验跨层次直接效应
$$Y_{ij} = \gamma_{00} + \gamma_{01}W_j + \gamma_{10}X_{ij} + u_{0j} + r_{ij}$$

**跨层次中介模型**：检验中介效应

**跨层次调节模型**：检验调节效应

# 第4章 研究结果

## 4.1 描述性统计与相关分析

| 变量 | M | SD | 1 | 2 | 3 | 4 |
|------|---|----|----|----|----|---|
| 1.包容型领导(L2) | 5.25 | 0.68 | 1 | | | |
| 2.团队异质性(L2) | 0.45 | 0.18 | 0.12 | 1 | | |
| 3.心理安全感(L1) | 4.85 | 0.92 | 0.42*** | 0.15* | 1 | |
| 4.敬业度(L1) | 4.68 | 1.05 | 0.38*** | 0.08 | 0.55*** | 1 |

## 4.2 零模型检验

敬业度的零模型：
- τ00 = 0.18（组间方差）
- σ² = 1.02（组内方差）
- **ICC(1) = 0.15**

15%的敬业度方差来自团队层面差异，支持使用HLM。

## 4.3 假设检验

### 4.3.1 主效应检验（H1, H2）

**表4-1 HLM分析结果**

| | 心理安全感 | 敬业度 |
|--|-----------|--------|
| **L1控制变量** | | |
| 性别 | 0.08 | 0.05 |
| 年龄 | 0.12* | 0.15** |
| 学历 | 0.06 | 0.08 |
| 工龄 | 0.10 | 0.12* |
| **L2控制变量** | | |
| 团队规模 | -0.05 | -0.03 |
| 团队年龄 | 0.08 | 0.06 |
| **自变量** | | |
| 包容型领导(L2) | **0.35***（γ01） | 0.22*** |
| 心理安全感(L1) | | **0.42***（β10） |
| **模型拟合** | | |
| R²(L1) | 0.22 | 0.38 |
| R²(L2) | 0.28 | 0.32 |

- **H1获得支持**：包容型领导→心理安全感（γ=0.35, p<0.001）
- **H2获得支持**：心理安全感→敬业度（β=0.42, p<0.001）

### 4.3.2 跨层次中介效应检验（H3）

采用Monte Carlo方法计算跨层次间接效应：

| 效应类型 | 估计值 | SE | 95% CI |
|----------|--------|-----|--------|
| 间接效应(a×b) | 0.15 | 0.04 | [0.08, 0.24] |
| 直接效应(c') | 0.22 | 0.06 | [0.10, 0.34] |
| 总效应(c) | 0.37 | 0.05 | [0.27, 0.47] |

间接效应95%CI不含0，**H3获得支持**：心理安全感起跨层次中介作用。

中介效应占比 = 0.15/0.37 = **40.5%**

### 4.3.3 跨层次调节效应检验（H4）

在模型中加入包容型领导×团队异质性的交互项：

| 效应 | 系数 | SE | t值 | p值 |
|------|------|-----|-----|-----|
| 包容型领导×团队异质性→心理安全感 | **0.18** | 0.07 | 2.57 | <0.05 |

**H4获得支持**：团队异质性正向调节包容型领导与心理安全感的关系。

**简单斜率分析**：
- 低异质性团队（M-1SD）：γ=0.22, p<0.01
- 高异质性团队（M+1SD）：γ=0.48, p<0.001

在高异质性团队中，包容型领导的效应（γ=0.48）是低异质性团队（γ=0.22）的2倍以上。

## 4.4 假设检验结果汇总

| 假设 | 内容 | 结果 |
|------|------|------|
| H1 | 包容型领导→心理安全感（+） | **支持** |
| H2 | 心理安全感→敬业度（+） | **支持** |
| H3 | 心理安全感的跨层次中介作用 | **支持** |
| H4 | 团队异质性的调节作用（+） | **支持** |

# 第5章 讨论与结论

## 5.1 主要发现讨论

### 跨层次影响机制
包容型领导作为团队层面变量，通过增强个体层面的心理安全感，提升员工敬业度。这验证了"自上而下"的领导影响过程。

### 心理安全感的关键作用
心理安全感解释了包容型领导对敬业度影响的40.5%，是关键的传导机制。包容型领导通过创造"心理安全"的团队氛围，使员工敢于投入工作。

### 团队异质性的边界条件
在高异质性团队中，包容型领导更加重要。多元化团队更需要领导的包容和接纳来克服差异带来的障碍。

## 5.2 理论贡献

1. **跨层次视角**：采用HLM正确处理嵌套数据，避免了层次谬误

2. **中介机制揭示**：验证心理安全感的跨层次中介作用

3. **边界条件识别**：发现团队异质性的调节作用，明确了包容型领导发挥作用的情境

## 5.3 实践启示

### 对组织
- 在多元化团队中优先培养包容型领导
- 将包容型领导纳入领导力发展项目

### 对领导者
- 展现开放、可得、易接近的行为
- 主动邀请和欣赏员工的不同贡献

### 对人力资源管理
- 在领导选拔中评估包容型领导特质
- 定期测量团队心理安全感水平

## 5.4 研究局限与展望

### 局限
- 横截面设计，因果推断受限
- 单一行业（科技企业），普适性有待检验
- 员工评价领导，可能存在同源偏差

### 展望
- 纵向追踪研究
- 扩展到不同行业和文化情境
- 探索其他中介机制（如心理资本）
