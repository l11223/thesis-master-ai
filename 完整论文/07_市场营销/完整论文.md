# 直播带货消费者冲动购买的前因组态研究
## ——基于fsQCA的分析

---

# 摘要

直播带货的爆发式增长带来了消费者冲动购买现象的普遍化。是什么因素组合导致了消费者在直播间的冲动购买？本研究突破传统线性因果思维，采用模糊集定性比较分析（fsQCA）方法，从组态视角探索直播带货情境下消费者冲动购买的前因组合。

基于刺激-机体-反应（S-O-R）理论和精细加工可能性模型（ELM），本研究构建了包含主播特质（专业性、吸引力）、直播氛围（互动性、稀缺性、娱乐性）、产品因素（价格折扣）和消费者特质（冲动性人格）的前因框架。通过对328名有直播购物经历消费者的问卷调查，运用fsQCA方法分析导致高/低冲动购买的前因组态。

研究发现：（1）价格折扣是高冲动购买的必要条件（一致性=0.92）；（2）存在四条导致高冲动购买的等效路径：专业主导型、互动驱动型、氛围刺激型和人格易感型，总体覆盖度为72%；（3）导致高冲动购买和低冲动购买的组态呈现非对称性，表明冲动购买的形成与抑制遵循不同逻辑。

**关键词**：直播带货；冲动购买；fsQCA；组态分析；非对称因果

# 第1章 引言

## 1.1 研究背景

### 1.1.1 直播电商的爆发式增长
直播带货已成为电商发展的新引擎。2023年中国直播电商市场规模突破4.9万亿元，用户规模超过5亿。

### 1.1.2 冲动购买现象的普遍性
直播带货的即时性、互动性和稀缺性特征容易引发消费者冲动购买。调查显示，超过60%的消费者有过直播间冲动消费经历。

### 1.1.3 传统研究方法的局限
已有研究多采用回归分析等传统方法，难以揭示多因素复杂组合效应和等效路径。

## 1.2 问题提出

1. 哪些因素组合会导致消费者高冲动购买？
2. 哪些因素组合会导致消费者低冲动购买？
3. 高/低冲动购买的形成机制是否对称？

## 1.3 研究方法选择

### 为什么选择fsQCA？
| 维度 | 回归分析 | fsQCA |
|------|----------|-------|
| 因果观 | 线性叠加 | 组态因果 |
| 变量关系 | 对称 | 非对称 |
| 等效性 | 不考虑 | 核心假设 |
| 适用情境 | 大样本 | 中等样本 |

# 第2章 理论基础与前因框架

## 2.1 理论基础

### 2.1.1 S-O-R模型
刺激（Stimulus）→ 机体（Organism）→ 反应（Response）
- 直播环境刺激 → 消费者心理状态 → 购买行为

### 2.1.2 精细加工可能性模型（ELM）
- 中央路径：理性评估产品信息
- 外周路径：依赖情境线索和启发式

## 2.2 前因变量识别

### 2.2.1 主播特质
- **专业性**：主播对产品知识的掌握程度
- **吸引力**：主播的外在形象和人格魅力

### 2.2.2 直播氛围
- **互动性**：主播与观众的实时互动程度
- **稀缺性**：限时限量的营销策略
- **娱乐性**：直播的趣味性和娱乐价值

### 2.2.3 产品因素
- **价格折扣**：相对日常售价的折扣力度

### 2.2.4 消费者特质
- **冲动性人格**：个体冲动购买的特质倾向

## 2.3 前因框架

```
┌─────────────────────────────────────────────┐
│              【前因条件】                     │
│                                              │
│  主播特质      直播氛围      产品/消费者     │
│  · 专业性      · 互动性      · 价格折扣     │
│  · 吸引力      · 稀缺性      · 冲动性人格   │
│               · 娱乐性                       │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
           【冲动购买行为】
             高 / 低
```

# 第4章 数据分析与结果

## 4.1 必要条件分析

一致性>0.9视为必要条件

| 前因条件 | 一致性 | 覆盖度 | 是否必要 |
|----------|--------|--------|----------|
| 主播专业性 | 0.85 | 0.72 | 否 |
| 主播吸引力 | 0.82 | 0.68 | 否 |
| 互动性 | 0.78 | 0.65 | 否 |
| 稀缺性 | 0.88 | 0.75 | 否 |
| 娱乐性 | 0.75 | 0.62 | 否 |
| **价格折扣** | **0.92** | **0.78** | **是** |
| 冲动性人格 | 0.72 | 0.58 | 否 |

**发现**：价格折扣是高冲动购买的必要条件（一致性=0.92）。即：**没有价格折扣，几乎不可能产生高冲动购买**。但价格折扣不是充分条件，还需要与其他条件组合。

## 4.2 充分条件分析——高冲动购买

### 真值表设置
- 频数阈值：3（案例数≥3）
- 一致性阈值：0.80
- PRI阈值：0.75

### 组态结果

| 条件 | 组态1 | 组态2 | 组态3 | 组态4 |
|------|-------|-------|-------|-------|
| | 专业主导型 | 互动驱动型 | 氛围刺激型 | 人格易感型 |
| 主播专业性 | ● | ● | ○ | ● |
| 主播吸引力 | ● | ○ | ● | - |
| 互动性 | ○ | ● | ● | ● |
| 稀缺性 | ● | ● | ● | ○ |
| 娱乐性 | - | ○ | ● | ● |
| 价格折扣 | ● | ● | ● | ● |
| 冲动性人格 | - | ● | ○ | ● |
| **原始覆盖度** | 0.35 | 0.28 | 0.32 | 0.25 |
| **唯一覆盖度** | 0.12 | 0.08 | 0.10 | 0.07 |
| **一致性** | 0.92 | 0.89 | 0.93 | 0.88 |

**总体解方案**
- 总体覆盖度：0.72
- 总体一致性：0.86

●=核心条件存在；○=核心条件缺失；-=无关条件

### 组态解读

**组态1：专业主导型**（覆盖度=0.35）
- 核心条件：高专业性 + 高吸引力 + 高稀缺性 + 高价格折扣
- 特征：主播的专业形象是触发冲动购买的关键
- 典型情境：专业美妆博主带货

**组态2：互动驱动型**（覆盖度=0.28）
- 核心条件：高专业性 + 高互动性 + 高稀缺性 + 高价格折扣 + 高冲动性人格
- 特征：直播间的热烈互动氛围激发冲动
- 典型情境：头部主播直播间的抢购氛围

**组态3：氛围刺激型**（覆盖度=0.32）
- 核心条件：高吸引力 + 高互动性 + 高稀缺性 + 高娱乐性 + 高价格折扣
- 特征：综合的感官刺激和氛围营造
- 典型情境：娱乐明星直播带货

**组态4：人格易感型**（覆盖度=0.25）
- 核心条件：高专业性 + 高互动性 + 高娱乐性 + 高价格折扣 + 高冲动性人格
- 特征：高冲动性人格消费者更容易被触发
- 典型情境：冲动型消费者的日常直播购物

## 4.3 充分条件分析——低冲动购买（非对称分析）

| 条件 | 组态A | 组态B |
|------|-------|-------|
| | 理性防御型 | 无兴趣型 |
| 主播专业性 | - | ○ |
| 主播吸引力 | ○ | ○ |
| 互动性 | ○ | - |
| 稀缺性 | ○ | ○ |
| 娱乐性 | - | ○ |
| 价格折扣 | ○ | ○ |
| 冲动性人格 | ○ | ○ |
| **原始覆盖度** | 0.42 | 0.38 |
| **一致性** | 0.88 | 0.85 |

**发现**：低冲动购买的组态与高冲动购买组态并非简单镜像关系，体现了**非对称因果**。

## 4.4 稳健性检验

### 调整一致性阈值
将一致性阈值从0.80调整为0.85，核心组态保持稳定。

### 调整频数阈值
将频数阈值从3调整为5，组态数量减少但核心模式不变。

# 第5章 讨论与结论

## 5.1 主要发现

### 5.1.1 价格折扣是必要非充分条件
价格折扣一致性达0.92，是高冲动购买的必要条件。这表明在直播带货情境下，**价格优惠是触发冲动购买的门槛条件**，但仅有价格优惠是不够的。

### 5.1.2 存在四条等效路径
四种组态代表了触发冲动购买的四条不同路径，体现了**等效性**（Equifinality）原则：殊途同归。

### 5.1.3 冲动购买具有非对称因果
高冲动购买和低冲动购买的形成遵循不同逻辑，不能简单认为"高的反面就是低"。

## 5.2 理论贡献

1. **方法论创新**：首次采用fsQCA方法研究直播带货冲动购买，揭示了传统方法难以发现的组态效应

2. **等效路径发现**：识别出四条导致高冲动购买的等效路径，丰富了冲动购买形成机制的理解

3. **非对称因果揭示**：验证了冲动购买形成与抑制的非对称性，为干预策略设计提供新思路

## 5.3 实践启示

### 对直播平台
- 建立价格监督机制，确保折扣真实性
- 根据不同触发路径设计差异化营销策略

### 对主播
- 专业型主播：强化专业形象和产品知识
- 娱乐型主播：营造综合感官体验氛围

### 对消费者
- 认识冲动购买的触发机制
- 识别自身是否属于高风险类型（高冲动性人格）
- 理性看待限时限量的稀缺性营销

### 对监管部门
- 关注虚假折扣问题
- 规范稀缺性营销手段
- 开展消费者教育

## 5.4 研究局限与展望

### 局限
- 横截面数据，难以检验因果关系
- 自我报告测量，可能存在回忆偏差
- 未区分不同产品类别

### 展望
- 纵向追踪研究
- 实验设计验证因果关系
- 细分产品类别的比较研究
- 结合眼动、皮肤电等生理指标
