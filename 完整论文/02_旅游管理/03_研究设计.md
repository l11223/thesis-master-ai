# 第3章 研究设计

## 3.1 研究情境选择

### 3.1.1 福建土楼概况

本研究选择福建土楼世界文化遗产地作为研究情境。福建土楼于2008年被列入《世界遗产名录》，是中国传统建筑文化的杰出代表。

福建土楼主要分布在闽西南山区，包括龙岩市永定区和漳州市南靖县、华安县等地。土楼以其独特的建筑形式——圆形或方形的大型土木结构住宅——闻名于世。这些建筑凝聚了客家先民的智慧，体现了中国传统建筑的天人合一理念。

### 3.1.2 选择福建土楼的理由

选择福建土楼作为研究情境，基于以下考虑：

**第一，多感官体验丰富。** 福建土楼具有丰富的多感官体验资源：
- 视觉：独特的圆楼/方楼建筑、青山绿水的自然环境
- 听觉：客家山歌、鸟鸣虫唱、流水潺潺
- 嗅觉：土木建筑的原木香、当地茶香、田园气息
- 味觉：客家美食、土楼茶文化
- 触觉：土木结构的质感、手工艺品体验

**第二，文化内涵深厚。** 福建土楼是客家文化的重要载体，承载着丰富的历史记忆和文化符号，有助于研究情感记忆和目的地依恋的形成。

**第三，研究可行性高。** 福建土楼景区游客量稳定，游客停留时间较长，便于开展现场调研。

## 3.2 样本与数据收集

### 3.2.1 问卷设计

问卷包括以下部分：
- 第一部分：多感官体验量表（25题）
- 第二部分：情感记忆量表（8题）
- 第三部分：目的地依恋量表（8题）
- 第四部分：旅游涉入度量表（6题）
- 第五部分：人口统计特征

问卷采用Likert 7点计分（1=完全不同意，7=完全同意）。

### 3.2.2 预调研

预调研于2024年3月在福建土楼永定景区进行，共收集有效问卷65份。预调研结果显示：
- 各量表Cronbach's α系数均>0.7
- 因子结构与预期一致
- 根据反馈微调部分题项措辞

### 3.2.3 正式调研

正式调研于2024年4月至6月在福建土楼永定景区和南靖景区进行。采用现场拦截问卷与在线回访相结合的方式：

**现场调研**：在景区出口处拦截游客，邀请其填写纸质问卷。为提高参与率，提供土楼特色明信片作为礼品。

**在线回访**：对愿意留下联系方式的游客，在其游览结束一周后通过微信发送电子问卷链接，收集补充数据。

## 3.3 变量测量

### 3.3.1 多感官体验

多感官体验的测量借鉴Agapito等（2017）开发的感官维度量表，并根据福建土楼情境进行调整，共25个题项，分为五个维度：

**视觉体验（5题项）**
- VIS1：土楼独特的建筑外观给我留下深刻印象
- VIS2：土楼周边的自然风光非常优美
- VIS3：土楼内部的空间布局很有特色
- VIS4：当地的传统服饰和装饰很有视觉吸引力
- VIS5：整个景区的色彩搭配让人感到舒适

**听觉体验（5题项）**
- AUD1：我在土楼听到了动听的客家山歌
- AUD2：土楼的自然声音（鸟鸣、流水等）让我感到放松
- AUD3：当地人的方言让我感受到独特的文化氛围
- AUD4：土楼的整体声音环境让人感到宁静
- AUD5：这里的声音让我联想到传统和历史

**嗅觉体验（5题项）**
- OLF1：土楼特有的土木香气让我印象深刻
- OLF2：当地茶香让我感到愉悦
- OLF3：这里的空气清新，带有自然的芬芳
- OLF4：当地美食的香气刺激了我的味蕾
- OLF5：土楼的气味让我联想到传统和自然

**味觉体验（5题项）**
- GUS1：客家美食的味道让我印象深刻
- GUS2：当地特色茶的口感非常好
- GUS3：这里的饮食体验让我感到满足
- GUS4：当地食物的独特风味让我难以忘怀
- GUS5：品尝当地美食是这次旅行的重要组成部分

**触觉体验（5题项）**
- TAC1：触摸土楼墙壁让我感受到历史的厚重
- TAC2：走在土楼的石板路上让我感到踏实
- TAC3：体验手工艺品的制作让我感到有趣
- TAC4：这里的温度和湿度让我感到舒适
- TAC5：与土楼建筑的触觉接触让我感到真实

### 3.3.2 情感记忆

情感记忆的测量借鉴Kim（2014）和Willander和Larsson（2006）的研究，共8个题项：

- EM1：游览土楼让我产生了强烈的情感体验
- EM2：土楼的某些场景让我想起了过去的美好回忆
- EM3：这次旅行将成为我珍贵的回忆
- EM4：土楼的感官体验（看到、听到、闻到的）让我情感涌动
- EM5：我在土楼感受到了一种独特的情感连接
- EM6：离开后我会时常想起在土楼的体验
- EM7：土楼的某些气味或声音让我想起特别的事情
- EM8：这次旅行在我心中留下了深刻的情感印记

### 3.3.3 目的地依恋

目的地依恋的测量借鉴Williams和Vaske（2003）的经典量表，共8个题项，分为两个维度：

**地方依赖（4题项）**
- PD1：福建土楼是我进行文化体验旅游的最佳选择
- PD2：对于我想要的旅游体验，没有地方可以替代福建土楼
- PD3：在福建土楼，我获得了比其他地方更大的满足
- PD4：如果我无法再来福建土楼，我会感到失落

**地方认同（4题项）**
- PI1：福建土楼对我来说有特殊的意义
- PI2：我对福建土楼有强烈的归属感
- PI3：福建土楼反映了我是一个怎样的人
- PI4：我觉得福建土楼是"我的"地方

### 3.3.4 旅游涉入度

旅游涉入度的测量借鉴Kyle等（2007）改编的涉入度量表，共6个题项：

- TI1：文化遗产旅游对我来说非常重要
- TI2：我对文化遗产旅游非常感兴趣
- TI3：文化遗产旅游是我生活中重要的一部分
- TI4：我愿意花大量时间规划文化遗产旅游
- TI5：与其他休闲活动相比，文化遗产旅游对我意义更大
- TI6：我认为自己是一个热爱文化遗产旅游的人

### 3.3.5 控制变量

- 性别（男=1，女=0）
- 年龄
- 学历
- 游览类型（重游=1，首次=0）
- 停留时间

## 3.4 分析方法

### 3.4.1 数据分析策略

本研究采用SmartPLS 4.0进行PLS-SEM分析，主要步骤包括：

1. **测量模型检验**：评估信度（α, CR）、收敛效度（AVE, 载荷）、判别效度（Fornell-Larcker, HTMT）

2. **结构模型检验**：评估共线性（VIF）、路径系数、R²、f²、Q²

3. **假设检验**：
   - 直接效应检验（H1, H2, H3）
   - 中介效应检验（H4，Bootstrap法）
   - 调节效应检验（H5）
   - 感官体验差异化效应检验（H1a-H1e）

### 3.4.2 二阶因子模型处理

多感官体验和目的地依恋均为二阶构念：
- 多感官体验 = 视觉 + 听觉 + 嗅觉 + 味觉 + 触觉
- 目的地依恋 = 地方依赖 + 地方认同

采用重复指标法（Repeated Indicators Approach）处理二阶因子模型。
