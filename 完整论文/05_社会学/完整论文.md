# 返乡青年参与乡村振兴的动机与路径研究
## ——基于浙江省L县的扎根理论分析

---

# 摘要

在乡村振兴战略深入实施的背景下，返乡青年作为乡村振兴的重要主体日益受到关注。他们为何选择返乡？如何参与乡村振兴？哪些因素影响其持续参与？本研究采用扎根理论方法，以浙江省L县为研究田野，通过对28名返乡青年的深度访谈，探索返乡青年参与乡村振兴的动机结构、参与路径和影响因素。

研究发现：（1）返乡青年的动机呈现"推-拉-促"三重结构：城市推力（生存压力、职业瓶颈）、乡村拉力（乡土情怀、发展机遇）和促发因素（政策支持、家庭需求）共同作用；（2）返乡青年参与乡村振兴的路径包括产业振兴路径（农业创业、乡村旅游）、文化振兴路径（文化传承、新媒体传播）和组织振兴路径（村务参与、合作社组建）三种类型；（3）持续参与受个人层面（成就感、能力匹配）、社会层面（社会支持、身份认同）和制度层面（政策稳定、基础设施）因素的影响。本研究提出"意义重构"作为核心范畴，揭示了返乡青年通过参与乡村振兴重新建构人生意义的过程机制。

**关键词**：返乡青年；乡村振兴；扎根理论；质性研究；意义重构

# 第1章 引言

## 1.1 研究背景

### 1.1.1 乡村振兴战略的提出
党的十九大提出乡村振兴战略，将其作为新时代"三农"工作的总抓手。乡村振兴需要人才支撑，青年人才的引进和培养是关键。

### 1.1.2 乡村人才流失问题
长期以来，农村青年向城市单向流动，导致乡村人才匮乏、老龄化严重。据统计，农村常住人口中60岁以上老年人占比超过20%。

### 1.1.3 返乡青年现象的兴起
近年来，越来越多的青年选择返乡创业、返乡就业，形成了"新返乡潮"。这一群体成为乡村振兴的重要力量。

## 1.2 问题提出

1. 返乡青年为何选择返乡？其动机结构是什么？
2. 返乡青年如何参与乡村振兴？有哪些典型路径？
3. 哪些因素影响返乡青年的持续参与？

## 1.3 研究意义

### 学术意义
- 丰富乡村振兴主体研究
- 拓展返乡青年研究视角
- 构建本土化理论框架

### 实践意义
- 为青年返乡政策提供参考
- 为乡村人才振兴提供策略

# 第2章 文献综述

## 2.1 乡村振兴研究
乡村振兴包括产业振兴、人才振兴、文化振兴、生态振兴、组织振兴五大方面。人才振兴是核心支撑。

## 2.2 返乡青年研究

### 2.2.1 概念界定
返乡青年是指曾在城市学习或工作，后返回农村地区生活和发展的青年群体（通常指18-45岁）。

### 2.2.2 返乡动机研究
已有研究从经济理性、情感因素、政策因素等角度探讨返乡动机，但缺乏系统性的理论建构。

### 2.2.3 返乡后的社会适应
研究关注返乡青年的身份认同、社会关系重建等问题，但对其参与乡村振兴的过程和机制探讨不足。

## 2.3 研究述评与本研究定位
已有研究多采用量化方法，缺乏对返乡青年主体经验的深入理解。本研究采用扎根理论方法，自下而上构建理论框架。

# 第3章 研究设计

## 3.1 研究方法选择

### 为何选择扎根理论
- 研究问题具有探索性
- 需要深入理解主体经验
- 目标是建构理论而非验证假设

### 程序化扎根理论
采用Strauss和Corbin（1998）的程序化扎根理论，通过三级编码（开放编码、主轴编码、选择性编码）逐步建构理论。

## 3.2 研究田野

### L县概况
浙江省L县位于浙西南山区，是典型的农业县。近年来积极推进乡村振兴，出台了一系列吸引青年返乡的政策。

### 选择L县的理由
- 返乡青年数量较多，便于抽样
- 返乡创业类型多样，便于比较
- 当地政府支持，便于调研

## 3.3 研究对象

### 抽样策略
采用理论抽样（Theoretical Sampling），根据理论构建的需要逐步选择访谈对象。

### 样本特征

| 特征 | 类别 | 人数 |
|------|------|------|
| 性别 | 男 | 18 |
| | 女 | 10 |
| 年龄 | 25-30岁 | 12 |
| | 31-35岁 | 10 |
| | 36-40岁 | 6 |
| 学历 | 大专 | 8 |
| | 本科 | 15 |
| | 硕士 | 5 |
| 返乡年限 | 1-2年 | 8 |

| | 电商 | 8 |
| | 民宿/旅游 | 6 |
| | 文创 | 4 |

## 3.4 数据收集

### 深度访谈
- 时长：60-120分钟
- 录音并转录
- 持续至理论饱和

### 参与观察
- 参加返乡青年创业分享会
- 走访返乡青年创业项目
- 田野笔记

### 文档资料
- 政府政策文件
- 媒体报道
- 返乡青年个人资料

## 3.5 数据分析

### NVivo 12辅助编码
- 自由节点（开放编码）
- 树状节点（主轴编码）
- 关系模型（选择性编码）

## 3.6 研究质量保障

| 标准 | 保障措施 |
|------|----------|
| 可信度 | 持续比较、同行审议 |
| 可转移性 | 厚描、情境说明 |
| 可依赖性 | 审计轨迹、编码手册 |
| 可确认性 | 反身性、三角验证 |

## 3.7 研究伦理
- 知情同意
- 匿名化处理
- 数据安全保管

# 第4章 研究发现

## 4.1 开放编码

从28份访谈转录中提取186个初始概念，归纳为45个初级范畴。

### 示例

| 原始资料 | 初始概念 | 范畴 |
|----------|----------|------|
| "城里房价太高，工资却涨不动..." | 城市生活压力 | 经济推力 |
| "在公司干了5年还是个小主管..." | 职业发展受阻 | 职业推力 |
| "老家有地有房，生活成本低..." | 乡村生活成本低 | 经济拉力 |
| "从小在村里长大，对这里有感情..." | 乡土情怀 | 情感拉力 |
| "政府给返乡创业的补贴挺多的..." | 创业补贴 | 政策因素 |
| "父母年纪大了，需要人照顾..." | 家庭责任 | 家庭因素 |

## 4.2 主轴编码

将45个范畴归纳为12个主范畴，形成三大维度。

### 4.2.1 返乡动机维度

**推力因素**
- 城市生存压力（房价、物价、通勤）
- 职业发展瓶颈（晋升受阻、工作倦怠）
- 城市归属感缺失（漂泊感、孤独感）

**拉力因素**
- 乡土情怀（家乡认同、乡愁）
- 发展机遇（创业空间、政策红利）
- 生活品质（自然环境、生活节奏）

**促发因素**
- 政策支持（创业补贴、税收优惠）
- 家庭需求（父母养老、子女教育）
- 关键事件（疫情、裁员、结婚）

### 4.2.2 参与路径维度

**产业振兴路径**
- 农业创业（生态农业、智慧农业）
- 乡村旅游（民宿、农家乐）
- 农村电商（直播带货、社区团购）

**文化振兴路径**
- 传统文化传承（非遗技艺、民俗活动）
- 新媒体传播（短视频、自媒体）
- 文创产品开发

**组织振兴路径**
- 村务参与（村委会、理事会）
- 合作社组建（农业合作社、共富工坊）
- 公益活动（乡村教育、扶贫帮困）

### 4.2.3 持续参与因素维度

**个人层面**
- 成就感（事业成功、社会认可）
- 能力匹配（专业对口、技能适用）
- 个人成长（学习机会、视野拓展）

**社会层面**
- 社会支持（家人支持、同伴网络）
- 身份认同（村民接纳、社会尊重）
- 人际关系（社会资本、信任网络）

**制度层面**
- 政策稳定（扶持政策、营商环境）
- 基础设施（网络、物流、交通）
- 公共服务（教育、医疗、养老）

## 4.3 选择性编码

### 核心范畴：意义重构

通过反复比较和理论敏感性分析，提炼出"**意义重构**"作为核心范畴。

返乡青年通过参与乡村振兴，经历了人生意义的重构过程：
- 从"城市漂泊者"到"乡村建设者"
- 从"被动谋生"到"主动追求"
- 从"个人成功"到"社会价值"

### 理论模型

```
         【动机结构】
    推力 + 拉力 + 促发因素
              │
              ▼
         【参与路径】
    产业/文化/组织 三条路径
              │
              ▼
         【意义重构】← 核心范畴
    身份重塑 + 价值实现
              │
              ▼
         【持续参与】
    个人/社会/制度 三层支持
```

## 4.4 理论饱和度检验

预留3份访谈资料进行饱和度检验，未发现新的范畴和关系，理论达到饱和。

# 第5章 讨论与结论

## 5.1 与既有理论对话

### 与推拉理论的对话
本研究发现的"推-拉-促"三重结构拓展了经典推拉理论，增加了"促发因素"维度。

### 与乡村振兴研究的对话
本研究识别的三条参与路径与乡村振兴"五个振兴"相对应，为理解青年参与提供了具体路径。

### 与意义建构理论的对话
"意义重构"的核心范畴呼应了Weick的意义建构理论，揭示了返乡青年的认同转变过程。

## 5.2 理论贡献

1. **构建了返乡青年参与乡村振兴的扎根理论**：提出"推-拉-促"动机结构、三条参与路径和三层支持因素

2. **提出"意义重构"核心范畴**：揭示返乡青年通过参与乡村振兴重建人生意义的深层机制

3. **丰富了乡村振兴主体研究**：从返乡青年主体视角理解乡村振兴的微观过程

## 5.3 政策建议

### 优化返乡创业支持政策
- 完善创业补贴和税收优惠
- 降低创业融资门槛
- 提供创业培训和指导

### 完善乡村公共服务
- 改善教育、医疗条件
- 完善网络、物流基础设施
- 优化营商环境

### 构建青年发展平台
- 建立返乡青年交流平台
- 搭建创业资源对接平台
- 营造尊重青年的社会氛围

## 5.4 研究局限与展望

### 局限
- 单一地区，可转移性受限
- 横截面数据，难以追踪动态变化
- 研究者主观性难以完全消除

### 未来方向
- 多地区比较研究
- 纵向追踪研究
- 量化验证研究
