# 短视频平台健康信息传播效果研究
## ——以抖音健康类账号为例

---

# 摘要

短视频平台已成为公众获取健康信息的重要渠道。短视频健康信息有何特征？什么因素影响其传播效果？对受众健康认知和行为有何影响？本研究采用内容分析与问卷调查相结合的方法，系统研究短视频平台健康信息的传播特征与效果。

研究一对抖音Top20健康类账号的1000条短视频进行内容分析；研究二对412名短视频用户进行问卷调查，基于精细加工可能性模型（ELM）检验健康信息特征对受众接受度和行为意向的影响。

研究结果表明：（1）内容分析发现，健康短视频以营养饮食（28.5%）和疾病预防（25.2%）为主要主题，医生账号占比最高（42%），真人出镜形式最常见（68%）；（2）效果调查发现，信息来源可信度（β=0.35）、内容质量（β=0.28）和呈现形式生动性（β=0.22）对健康信息接受度均有显著正向影响；（3）健康信息接受度对健康行为意向有显著正向影响（β=0.48）；（4）健康素养负向调节信息来源可信度与接受度的关系——高健康素养者对来源可信度的依赖更低。

**关键词**：短视频；健康传播；内容分析；精细加工可能性模型；健康素养

# 第1章 引言

## 1.1 研究背景

### 1.1.1 短视频的爆发式增长
抖音、快手等短视频平台用户规模超过10亿，日活跃用户超过7亿。短视频已成为最主要的信息获取渠道之一。

### 1.1.2 健康传播的新媒体转向
传统健康传播以医院、媒体为主要渠道。短视频时代，普通医生、营养师、健身教练等成为健康信息的重要传播者。

### 1.1.3 健康信息质量问题
短视频的低门槛和碎片化特征带来健康信息质量参差不齐的问题。伪科学、夸大宣传等问题时有发生。

## 1.2 研究问题

**RQ1**：抖音健康类短视频的内容特征是什么？
**RQ2**：什么因素影响健康类短视频的传播效果？
**RQ3**：健康类短视频对受众健康认知和行为有何影响？

## 1.3 研究框架

```
【研究一：内容分析】              【研究二：效果调查】
                                     
抖音健康短视频 ──────────────→ 信息特征
· 主题分布                         · 来源可信度
· 来源特征                         · 内容质量
· 呈现形式                         · 呈现生动性
· 传播数据                               │
                                         ▼
                                  健康信息接受度
                                         │
                                         ▼
                                  健康行为意向
```

# 第2章 文献综述

## 2.1 健康传播研究

### 健康传播的定义
健康传播是指通过各种传播渠道和策略，向公众传递健康相关信息，以促进健康认知和行为改变的过程（Schiavo, 2007）。

### 新媒体健康传播
社交媒体、短视频等新媒体改变了健康传播的格局。用户既是信息接收者，也是信息生产者和传播者。

## 2.2 短视频研究

### 短视频的传播特征
- 碎片化：时长短，信息密度高
- 视觉化：以视觉符号为主要载体
- 社交化：强调互动和分享
- 算法推荐：个性化内容分发

### 短视频与健康传播
健康类短视频在疫情期间迅速增长，成为公众获取健康信息的重要渠道。

## 2.3 理论基础

### 精细加工可能性模型（ELM）
Petty和Cacioppo（1986）提出的ELM模型认为，态度改变有两条路径：
- **中央路径**：仔细考虑信息内容的质量
- **外周路径**：依赖情境线索（如来源可信度）进行快速判断

### 健康信念模型（HBM）
健康信念模型认为，健康行为受感知威胁、感知收益、自我效能等因素影响。

## 2.4 研究假设

**H1**：信息来源可信度对健康信息接受度具有正向影响
**H2**：内容质量对健康信息接受度具有正向影响
**H3**：呈现形式生动性对健康信息接受度具有正向影响
**H4**：健康信息接受度对健康行为意向具有正向影响
**H5**：健康素养调节信息特征与接受度之间的关系

# 第3章 研究一：内容分析

## 3.1 研究设计

### 样本选择
- 平台：抖音
- 账号：健康类头部账号Top20（按粉丝数排名）
- 样本：每账号随机抽取50条视频，共1000条
- 时间：2024年1月-6月

### 编码框架

| 类目 | 编码项 | 操作定义 |
|------|--------|----------|
| **主题** | 疾病预防 | 讲解疾病预防知识 |
| | 营养饮食 | 讲解饮食营养知识 |
| | 运动健身 | 讲解运动健身方法 |
| | 心理健康 | 讲解心理健康知识 |
| | 医疗科普 | 讲解医学专业知识 |
| **来源** | 医生 | 账号主体为执业医生 |
| | 营养师 | 账号主体为营养师 |
| | 健身教练 | 账号主体为健身教练 |
| | 普通用户 | 账号主体为普通用户 |
| **形式** | 真人出镜 | 主播真人出镜讲解 |
| | 图文解说 | 图片配合文字解说 |
| | 动画演示 | 动画形式呈现 |
| | 情景剧 | 故事情景演绎 |
| **质量指标** | 引用来源 | 是否标注信息来源 |
| | 专业术语 | 是否使用专业术语 |
| | 误导信息 | 是否存在明显错误 |
| **传播数据** | 点赞数 | 视频点赞数量 |
| | 评论数 | 视频评论数量 |
| | 转发数 | 视频转发数量 |

### 编码员信度
- 编码员：2名传播学研究生
- 培训：10%样本共同编码
- Krippendorff's α = 0.85（>0.8，可靠）

## 3.2 内容分析结果

### 3.2.1 主题分布

| 主题 | 数量 | 百分比 |
|------|------|--------|
| 营养饮食 | 285 | 28.5% |
| 疾病预防 | 252 | 25.2% |
| 运动健身 | 198 | 19.8% |
| 医疗科普 | 165 | 16.5% |
| 心理健康 | 100 | 10.0% |

**发现**：营养饮食和疾病预防是最热门的健康主题。

### 3.2.2 来源特征

| 来源 | 数量 | 百分比 | 平均点赞数 |
|------|------|--------|------------|
| 医生 | 420 | 42.0% | 12.5万 |
| 营养师 | 235 | 23.5% | 8.2万 |
| 健身教练 | 218 | 21.8% | 15.8万 |
| 普通用户 | 127 | 12.7% | 5.3万 |

**发现**：医生账号占比最高，但健身教练的平均点赞数最高。

### 3.2.3 呈现形式

| 形式 | 数量 | 百分比 |
|------|------|--------|
| 真人出镜 | 680 | 68.0% |
| 图文解说 | 152 | 15.2% |
| 动画演示 | 98 | 9.8% |
| 情景剧 | 70 | 7.0% |

### 3.2.4 内容质量

| 质量指标 | 比例 |
|----------|------|
| 标注信息来源 | 35.2% |
| 使用专业术语 | 58.5% |
| 存在误导信息 | 8.5% |

**发现**：仅35.2%的视频标注了信息来源，8.5%存在误导信息。

### 3.2.5 主题与传播效果

| 主题 | 平均点赞 | 平均评论 | 平均转发 |
|------|----------|----------|----------|
| 运动健身 | 18.2万 | 3,200 | 1,850 |
| 营养饮食 | 12.5万 | 2,800 | 1,520 |
| 疾病预防 | 8.5万 | 1,950 | 980 |
| 医疗科普 | 6.2万 | 1,520 | 720 |
| 心理健康 | 5.8万 | 2,100 | 650 |

**发现**：运动健身类视频传播效果最好。

# 第4章 研究二：效果调查

## 4.1 研究设计

### 样本
- 对象：过去3个月内观看过健康类短视频的用户
- 平台：问卷星
- 有效问卷：412份

### 变量测量

**信息来源可信度**（Ohanian, 1990）
- 专业性、可信度、吸引力
- 6题项，α=0.88

**内容质量**（自编）
- 准确性、有用性、完整性
- 5题项，α=0.85

**呈现形式生动性**（自编）
- 趣味性、吸引力、易理解
- 4题项，α=0.82

**健康信息接受度**（改编）
- 4题项，α=0.86

**健康行为意向**（改编自HBM）
- 5题项，α=0.89

**健康素养**（HLS-EU简版）
- 6题项，α=0.84

## 4.2 调查结果

### 4.2.1 样本特征

| 特征 | 类别 | 百分比 |
|------|------|--------|
| 性别 | 女 | 62.4% |
| 年龄 | 18-25岁 | 32.5% |

| | 每周多次 | 38.5% |

### 4.2.3 假设检验

**表4-1 回归分析结果**

| | 健康信息接受度 | 健康行为意向 |
|--|---------------|--------------|
| 来源可信度 | **0.35*** | |
| 内容质量 | **0.28*** | |
| 呈现生动性 | **0.22*** | |
| 信息接受度 | | **0.48*** |
| R² | 0.45 | 0.38 |

- **H1-H4均获得支持**

### 4.2.4 调节效应检验

来源可信度×健康素养→信息接受度：β=-0.15, p<0.05

**简单斜率分析**：
- 低健康素养者：来源可信度→接受度，β=0.50, p<0.001

**H5获得支持**：高健康素养者对来源可信度的依赖更低。

# 第5章 讨论与结论

## 5.1 主要发现

### 5.1.1 内容特征
- 营养饮食和疾病预防是主流主题
- 医生账号占主导，但健身教练传播效果更好
- 信息质量参差，仅35%标注来源

### 5.1.2 传播效果
- 来源可信度、内容质量、呈现生动性均影响接受度
- 来源可信度影响最强（ELM外周路径）
- 健康素养调节来源可信度的影响

### 5.1.3 行为影响
- 信息接受度显著正向影响健康行为意向

## 5.2 理论贡献

1. **拓展ELM在短视频情境的应用**：验证了中央路径（内容质量）和外周路径（来源可信度、生动性）的作用

2. **揭示健康素养的调节作用**：高健康素养者更依赖信息内容本身进行判断

3. **丰富短视频健康传播研究**：提供了内容特征的实证描述

## 5.3 实践建议

### 对健康信息发布者
- 医生等专业人士可发挥可信度优势
- 注重标注信息来源，提升可信度
- 采用生动形式，但不牺牲准确性

### 对平台
- 加强健康信息审核机制
- 优先推荐专业账号内容
- 对误导信息进行标注或下架

### 对公众
- 提升健康素养，批判性评估信息
- 关注信息来源的专业资质
- 重要健康决策应咨询专业人士

### 对监管部门
- 出台短视频健康信息规范
- 建立健康信息辟谣机制
- 开展公众健康素养教育

## 5.4 研究局限与展望

### 局限
- 内容分析仅限抖音平台
- 效果研究为自我报告
- 未追踪实际健康行为改变

### 展望
- 多平台比较研究
- 实验设计验证因果关系
- 纵向追踪健康行为改变
