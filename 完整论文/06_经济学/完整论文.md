# 数字普惠金融对居民消费升级的影响研究
## ——基于中国省级面板数据的实证分析

---

# 摘要

在数字经济蓬勃发展和扩大内需战略深入实施的背景下，数字普惠金融与居民消费升级的关系成为重要研究议题。数字普惠金融是否促进了居民消费升级？其影响机制是什么？在不同地区和城乡之间是否存在差异？本研究利用2011-2022年中国31个省份的面板数据，实证检验数字普惠金融对居民消费升级的影响及其作用机制。

研究结果表明：（1）数字普惠金融显著促进了居民消费升级（β=0.156, p<0.01），且在一系列稳健性检验后结论依然成立；（2）从结构维度看，数字普惠金融的使用深度对消费升级的促进作用最强（β=0.182），其次是覆盖广度（β=0.135）和数字化程度（β=0.098）；（3）机制检验表明，数字普惠金融通过收入效应（提高居民收入）和信贷约束缓解效应（缓解流动性约束）两条路径影响消费升级；（4）异质性分析显示，数字普惠金融对消费升级的促进作用在中西部地区强于东部地区，在农村地区强于城镇地区，体现出"普惠"特征。

**关键词**：数字普惠金融；消费升级；面板数据；中介效应；异质性分析

# 第1章 引言

## 1.1 研究背景

### 1.1.1 消费升级战略的提出
党的二十大报告指出，要着力扩大内需，增强消费对经济发展的基础性作用。消费升级是扩大内需的重要途径。

### 1.1.2 数字普惠金融的快速发展
以移动支付、互联网信贷、在线理财为代表的数字普惠金融在中国迅速发展。北京大学数字金融研究中心数据显示，中国数字普惠金融指数从2011年的40.0上升到2022年的450.3。

### 1.1.3 金融支持消费升级的重要性
金融服务是支持居民消费的重要基础设施。数字普惠金融通过降低金融服务门槛、提高金融可得性，可能对居民消费产生重要影响。

## 1.2 问题提出

1. 数字普惠金融是否促进了居民消费升级？
2. 数字普惠金融影响消费升级的机制是什么？
3. 上述影响是否存在区域和城乡异质性？

## 1.3 研究意义

### 理论意义
- 丰富数字普惠金融经济效应研究
- 拓展消费升级影响因素研究
- 揭示数字普惠金融影响消费的机制

### 实践意义
- 为数字普惠金融发展政策提供依据
- 为扩大消费政策设计提供参考

# 第2章 文献综述与理论分析

## 2.1 数字普惠金融研究

### 概念界定
数字普惠金融是指通过数字技术手段（移动互联网、大数据、云计算等）提供的普惠性金融服务（郭峰等，2020）。

### 测度方法
北京大学数字普惠金融指数（PKU-DFIIC）是目前最权威的测度指标，包括覆盖广度、使用深度和数字化程度三个维度。

### 经济效应研究
已有研究发现数字普惠金融能够促进经济增长（谢绚丽等，2018）、创业创新（梁榜和张建华，2019）、减少贫困（傅秋子和黄益平，2018）。

## 2.2 居民消费升级研究

### 消费升级的内涵
消费升级是指居民消费结构从生存型消费向发展型、享受型消费转变的过程（臧旭恒，2019）。

### 消费升级的测度
常用指标包括恩格尔系数、服务消费占比、发展享受型消费占比等。

### 影响因素研究
收入水平、社会保障、金融发展等是影响消费升级的重要因素（方福前和田鸽，2021）。

## 2.3 理论分析与研究假设

### 理论基础
- **消费函数理论**：收入是决定消费的首要因素
- **流动性约束理论**：信贷约束影响消费平滑能力
- **预防性储蓄理论**：不确定性影响消费决策

### 影响机制

**机制一：收入效应**
数字普惠金融通过促进创业就业、提高资产收益等渠道增加居民收入，进而促进消费升级。

**机制二：信贷约束缓解效应**
数字普惠金融降低金融服务门槛，缓解居民流动性约束，增强消费能力。

**机制三：支付便利效应**
移动支付降低交易成本，便利消费行为，可能促进消费扩张。

### 研究假设
**H1**：数字普惠金融对居民消费升级具有显著促进作用
**H2**：数字普惠金融通过收入效应促进消费升级
**H3**：数字普惠金融通过信贷约束缓解效应促进消费升级
**H4**：数字普惠金融对消费升级的影响存在区域异质性
**H5**：数字普惠金融对消费升级的影响存在城乡异质性

# 第3章 研究设计

## 3.1 模型设定

### 基准回归模型
$$Upgrade_{it} = \alpha + \beta_1 DIF_{it} + \gamma X_{it} + \mu_i + \lambda_t + \varepsilon_{it}$$

其中：
- $Upgrade_{it}$：居民消费升级指数
- $DIF_{it}$：数字普惠金融指数
- $X_{it}$：控制变量向量
- $\mu_i$：个体固定效应
- $\lambda_t$：时间固定效应

### 中介效应模型
$$M_{it} = \alpha_1 + \beta_1 DIF_{it} + \gamma_1 X_{it} + \mu_i + \lambda_t + \varepsilon_{it}$$
$$Upgrade_{it} = \alpha_2 + \beta_2 DIF_{it} + \beta_3 M_{it} + \gamma_2 X_{it} + \mu_i + \lambda_t + \varepsilon_{it}$$

## 3.2 变量选取

### 被解释变量：居民消费升级（Upgrade）
采用恩格尔系数的倒数衡量（1/恩格尔系数），数值越大代表消费升级程度越高。

### 核心解释变量：数字普惠金融（DIF）
采用北京大学数字普惠金融指数（对数化处理）。同时分析三个分维度：
- 覆盖广度（Coverage）
- 使用深度（Depth）
- 数字化程度（Digitization）

### 控制变量
| 变量 | 符号 | 测度方法 |
|------|------|----------|
| 经济发展 | pgdp | 人均GDP的自然对数 |
| 城镇化率 | urban | 城镇人口/总人口 |
| 产业结构 | industry | 第三产业增加值占比 |
| 教育水平 | edu | 平均受教育年限 |
| 社会保障 | social | 社会保障支出占财政支出比重 |

### 中介变量
- 居民收入（income）：人均可支配收入对数
- 信贷约束（credit）：消费信贷/居民收入

## 3.3 数据来源

| 数据 | 来源 |
|------|------|
| 数字普惠金融指数 | 北京大学数字金融研究中心 |
| 消费支出、恩格尔系数 | 《中国统计年鉴》 |
| 人均GDP、城镇化率等 | 《中国统计年鉴》、EPS数据库 |

**样本**：2011-2022年31个省份，共372个观测值

## 3.4 描述性统计

| 变量 | 均值 | 标准差 | 最小值 | 最大值 |
|------|------|--------|--------|--------|
| Upgrade | 3.25 | 0.42 | 2.38 | 4.52 |
| DIF | 5.12 | 0.85 | 2.68 | 6.12 |
| pgdp | 10.58 | 0.52 | 9.25 | 11.85 |
| urban | 0.58 | 0.12 | 0.35 | 0.89 |
| industry | 0.48 | 0.08 | 0.32 | 0.82 |
| edu | 8.85 | 1.25 | 6.52 | 12.35 |
| social | 0.15 | 0.04 | 0.08 | 0.25 |

# 第4章 实证结果与分析

## 4.1 基准回归结果

| 变量 | (1)OLS | (2)FE | (3)FE+Year |
|------|--------|-------|------------|
| DIF | 0.182*** | 0.156*** | 0.148*** |
| | (0.025) | (0.028) | (0.026) |
| pgdp | | 0.285*** | 0.268*** |
| urban | | 0.125** | 0.118** |
| industry | | 0.095* | 0.088* |
| edu | | 0.068** | 0.062* |
| social | | 0.045 | 0.042 |
| 个体固定 | No | Yes | Yes |
| 时间固定 | No | No | Yes |
| N | 372 | 372 | 372 |
| R² | 0.32 | 0.68 | 0.72 |

注：括号内为聚类稳健标准误；*, **, ***分别表示10%、5%、1%显著水平

**结论**：数字普惠金融对消费升级有显著正向影响（β=0.148, p<0.01），**H1获得支持**。

## 4.2 稳健性检验

### 4.2.1 替换被解释变量
采用发展享受型消费占比替换恩格尔系数倒数，结论稳健（β=0.135, p<0.01）。

### 4.2.2 替换核心解释变量
采用数字普惠金融指数的一阶滞后项，结论稳健（β=0.142, p<0.01）。

### 4.2.3 剔除直辖市样本
剔除北京、天津、上海、重庆后，结论稳健（β=0.152, p<0.01）。

### 4.2.4 缩尾处理
对主要变量进行1%和99%分位数缩尾，结论稳健（β=0.145, p<0.01）。

## 4.3 内生性处理

### 4.3.1 工具变量法
采用各省地形起伏度（Terrain）作为工具变量。理由：
- 相关性：地形影响数字基础设施建设
- 外生性：地形不直接影响消费升级

**第一阶段**：Terrain与DIF显著负相关（β=-0.285, p<0.01），F=42.5>10

**第二阶段**：DIF对Upgrade仍显著正向（β=0.162, p<0.01）

### 4.3.2 系统GMM
采用系统广义矩估计方法，结论稳健（β=0.138, p<0.01）。AR(2)检验和Hansen检验均通过。

## 4.4 维度分析

| 维度 | 系数 | 标准误 | 排序 |
|------|------|--------|------|
| 使用深度 | 0.182*** | 0.032 | **1** |
| 覆盖广度 | 0.135*** | 0.028 | 2 |
| 数字化程度 | 0.098*** | 0.025 | 3 |

**发现**：使用深度对消费升级的促进作用最强。

## 4.5 机制检验

### 4.5.1 收入效应

| | 第一阶段 | 第二阶段 |
|--|----------|----------|
| DIF→income | 0.125*** | |
| income→Upgrade | | 0.285*** |
| DIF→Upgrade | | 0.108*** |

Sobel检验：Z=3.85, p<0.001
中介效应占比：27.0%

**H2获得支持**：收入效应成立。

### 4.5.2 信贷约束缓解效应

| | 第一阶段 | 第二阶段 |
|--|----------|----------|
| DIF→credit | 0.152*** | |
| credit→Upgrade | | 0.198*** |
| DIF→Upgrade | | 0.118*** |

Sobel检验：Z=4.12, p<0.001
中介效应占比：20.3%

**H3获得支持**：信贷约束缓解效应成立。

## 4.6 异质性分析

### 4.6.1 区域异质性

| 地区 | 系数 | 标准误 |
|------|------|--------|
| 东部 | 0.098** | 0.038 |
| 中部 | 0.168*** | 0.042 |
| 西部 | 0.185*** | 0.045 |

中西部地区系数显著高于东部（Chow检验：F=4.25, p<0.05）

**H4获得支持**：数字普惠金融的"普惠"效应在中西部更强。

### 4.6.2 城乡异质性

| 地区 | 系数 | 标准误 |
|------|------|--------|
| 城镇 | 0.118*** | 0.032 |
| 农村 | 0.195*** | 0.048 |

农村地区系数显著高于城镇（差异检验：t=2.85, p<0.01）

**H5获得支持**：数字普惠金融对农村消费升级的促进作用更强。

# 第5章 结论与政策建议

## 5.1 主要结论

1. **数字普惠金融显著促进消费升级**：系数为0.148，即数字普惠金融指数每提高1%，消费升级指数提高0.148%

2. **使用深度的促进作用最强**：相比覆盖广度和数字化程度，使用深度对消费升级的贡献最大

3. **收入效应和信贷约束缓解效应是主要机制**：分别贡献了27.0%和20.3%的中介效应

4. **存在显著的区域和城乡异质性**：中西部和农村地区的促进作用更强，体现"普惠"特征

## 5.2 政策建议

### 5.2.1 深化数字普惠金融发展
- 加强数字金融基础设施建设
- 推动数字金融产品创新
- 提升数字金融服务的使用深度

### 5.2.2 优化数字普惠金融结构
- 重点发展消费信贷服务
- 完善数字支付生态系统
- 拓展数字理财服务

### 5.2.3 缩小区域数字鸿沟
- 加大中西部数字基础设施投入
- 推动农村数字金融服务下沉
- 开展数字金融素养培训

### 5.2.4 促进城乡均衡发展
- 发展农村数字普惠金融
- 支持农村消费信贷发展
- 完善农村电商物流体系

## 5.3 研究不足与展望

### 不足
- 省级数据，难以捕捉微观异质性
- 消费升级测度相对粗糙
- 未能检验数字普惠金融的非线性效应

### 展望
- 使用家庭微观数据进行深入分析
- 构建多维消费升级指标体系
- 探索数字普惠金融的最优发展水平
