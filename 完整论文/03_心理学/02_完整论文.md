# 社交媒体使用对大学生焦虑的影响研究
## ——上行社会比较的中介作用与自尊的调节效应

---

# 第2章 文献综述

## 2.1 社交媒体使用

### 2.1.1 概念界定
社交媒体（Social Media）是指基于互联网的应用程序，允许用户创建和交换用户生成内容（Kaplan & Haenlein, 2010）。典型的社交媒体平台包括微信、微博、抖音、小红书、Instagram、Facebook等。

### 2.1.2 社交媒体使用强度
社交媒体使用强度（Social Media Use Intensity）是指个体使用社交媒体的频率、时长和卷入程度。本研究关注的是被动性使用（浏览他人内容）而非主动性使用（发布内容）。

## 2.2 社会比较理论

### 2.2.1 理论发展
Festinger（1954）提出社会比较理论，认为人类具有评估自身能力和观点的需求。上行社会比较是指与比自己优秀的人进行比较。

### 2.2.2 社交媒体与上行比较
社交媒体的"精心策划的自我呈现"特征使其成为上行社会比较的温床（Vogel et al., 2014）。

## 2.3 焦虑

### 2.3.1 概念与分类
Spielberger（1972）区分了状态焦虑（State Anxiety）和特质焦虑（Trait Anxiety）。本研究关注状态焦虑。

### 2.3.2 测量工具
采用状态-特质焦虑量表（STAI）进行测量。

## 2.4 自尊

### 2.4.1 概念界定
自尊（Self-esteem）是指个体对自我价值的总体评价（Rosenberg, 1965）。

### 2.4.2 保护作用
自尊可能缓冲社会比较的负面影响。高自尊个体在面对上行比较时，可能采用更积极的认知策略。

## 2.5 研究假设

**H1**：社交媒体使用强度对上行社会比较具有显著正向影响
**H2**：上行社会比较对焦虑具有显著正向影响
**H3**：社交媒体使用强度对焦虑具有显著正向影响
**H4**：上行社会比较在社交媒体使用强度与焦虑之间起中介作用
**H5**：自尊负向调节上行社会比较与焦虑之间的关系

# 第3章 研究设计

## 3.1 样本与数据收集

### 3.1.1 样本选择
- 对象：中国高校在校大学生
- 方式：线上问卷（问卷星）
- 时间：2024年4-5月

### 3.1.2 样本特征（N=526）
| 变量 | 类别 | 百分比 |
|------|------|--------|
| 性别 | 男 | 42.2% |
| | 女 | 57.8% |
| 年级 | 大一 | 22.4% |
| | 大二 | 28.5% |
| | 大三 | 26.8% |
| | 大四 | 22.3% |
| 日均使用时长 | <2小时 | 18.6% |
| | 2-4小时 | 45.2% |
| | >4小时 | 36.2% |

## 3.2 变量测量

### 3.2.1 社交媒体使用强度
改编自Ellison等（2007）的Facebook使用强度量表，8题项，α=0.88

### 3.2.2 上行社会比较
采用Gibbons和Buunk（1999）的社会比较取向量表，11题项，α=0.85

### 3.2.3 焦虑
采用STAI状态焦虑分量表（Spielberger, 1970），20题项，α=0.92

### 3.2.4 自尊
采用Rosenberg自尊量表（1965），10题项，α=0.87

## 3.3 分析方法
- 软件：SPSS 27.0 + AMOS 26.0
- 方法：验证性因子分析（CFA）+ 结构方程模型（SEM）
- 中介检验：Bootstrap法（5000次）
- 调节检验：潜变量交互效应

# 第4章 研究结果

## 4.1 共同方法偏差检验
Harman单因子检验：第一因子解释方差28.6%（<40%），无严重共同方法偏差。

## 4.2 验证性因子分析
四因子模型拟合良好：χ²/df=2.35, RMSEA=0.051, CFI=0.95, TLI=0.94

## 4.3 描述性统计与相关分析

| 变量 | M | SD | 1 | 2 | 3 | 4 |
|------|---|----|----|----|----|---|
| 1.社交媒体使用 | 4.52 | 1.08 | 1 | | | |
| 2.上行比较 | 4.28 | 1.15 | .45*** | 1 | | |
| 3.焦虑 | 3.85 | 1.22 | .38*** | .52*** | 1 | |
| 4.自尊 | 4.65 | 1.05 | -.18*** | -.32*** | -.45*** | 1 |

## 4.4 假设检验

### 4.4.1 直接效应
| 路径 | β | p |
|------|---|---|
| 社交媒体使用→上行比较 | 0.42 | <.001 |
| 上行比较→焦虑 | 0.45 | <.001 |
| 社交媒体使用→焦虑 | 0.28 | <.001 |

### 4.4.2 中介效应
- 间接效应 = 0.42 × 0.45 = 0.19
- 95% CI = [0.13, 0.26]，不含0，中介效应显著
- 中介效应占比 = 0.19/(0.19+0.28) = 40.4%
- **H4获得支持：部分中介**

### 4.4.3 调节效应
- 交互项（上行比较×自尊）→焦虑：β = -0.18, p < .01
- **H5获得支持**

简单斜率分析：
- 低自尊（M-1SD）：β = 0.63, p < .001
- 高自尊（M+1SD）：β = 0.27, p < .001

# 第5章 讨论与结论

## 5.1 主要发现

1. **社交媒体使用促进上行社会比较**：β=0.42，支持社交媒体作为社会比较"温床"的观点

2. **上行社会比较导致焦虑**：β=0.45，与社会比较理论预测一致

3. **中介机制**：上行社会比较解释了社交媒体使用影响焦虑的40.4%

4. **自尊的保护作用**：高自尊个体的焦虑反应（β=0.27）显著低于低自尊个体（β=0.63）

## 5.2 理论贡献

1. 将社会比较理论应用于社交媒体情境，验证了其解释力
2. 揭示了上行社会比较的中介机制
3. 验证了自尊的保护性调节作用
4. 在中国大学生群体中验证了西方理论的适用性

## 5.3 实践建议

### 对大学生
- 意识到社交媒体上的"精心策划"特性
- 减少被动性浏览，增加主动性社交
- 培养多元化的自我评价标准

### 对高校
- 开展媒体素养教育
- 关注低自尊学生群体
- 提供心理咨询资源

### 对平台
- 优化算法，减少引发社会比较的内容推送
- 增加真实性提示功能

## 5.4 局限与展望

1. 横截面设计，因果推断受限
2. 自我报告测量，可能存在偏差
3. 未区分不同类型的社交媒体
4. 未来可采用纵向设计、体验抽样法
