# 第3章 研究设计

## 3.1 样本与数据收集

### 3.1.1 样本选择

本研究以中国制造业企业为研究对象，选择制造业的原因如下：

第一，制造业是数字化转型的重要领域。中国制造业正处于从"制造大国"向"制造强国"转型的关键时期，数字化转型是实现这一转型的核心驱动力（Li et al., 2020）。

第二，制造业面临较高的环境动态性。技术快速迭代、全球竞争加剧、客户需求多变等因素，使制造业企业面临显著的环境不确定性，为研究环境动态性的调节作用提供了合适的情境。

第三，制造业的创新绩效便于测量。制造业企业的创新活动相对明确，新产品开发、工艺改进等创新成果便于识别和评估。

本研究的调研对象为制造业企业的中高层管理者（总经理、副总经理、部门总监等），原因在于：（1）中高层管理者对企业数字化转型战略和实施情况有全面了解；（2）中高层管理者能够准确评估企业的组织韧性和创新绩效；（3）中高层管理者的判断更具代表性和权威性。

### 3.1.2 数据收集过程

本研究的数据收集分为预调研和正式调研两个阶段。

**（1）预调研阶段**

预调研于2024年3月进行，主要目的是检验问卷的信效度，并根据反馈优化问卷设计。预调研通过线上问卷平台（问卷星）发放，共收集有效问卷58份。

预调研结果显示，各量表的Cronbach's α系数均大于0.7，表明量表具有良好的信度。探索性因子分析结果显示，各量表的因子结构与预期一致，表明量表具有良好的效度。根据预调研反馈，对部分题项的措辞进行了微调。

**（2）正式调研阶段**

正式调研于2024年4月至6月进行，采用线上线下相结合的方式：

线上渠道：通过LinkedIn、脉脉等职业社交平台，向制造业企业中高层管理者发放问卷链接。同时，借助MBA校友网络、行业协会会员名录等资源进行定向邀请。

线下渠道：委托专业调研公司，在长三角、珠三角等制造业发达地区开展实地调研，采用一对一访谈式问卷填写方式。

为提高问卷回收率和数据质量，采取了以下措施：（1）在问卷开头说明研究目的和保密承诺；（2）设置多道反向计分题和注意力检测题；（3）提供小额调研酬金（微信红包）作为激励。

## 3.2 变量测量

本研究涉及的变量包括数字化转型（自变量）、组织韧性（中介变量）、创新绩效（因变量）、环境动态性（调节变量）以及控制变量。所有量表均采用Likert 7点计分（1=完全不同意，7=完全同意）。

### 3.2.1 数字化转型

数字化转型的测量借鉴Verhoef等（2021）开发的量表，包括数字资源、数字能力、数字文化三个维度，共12个题项。该量表在已有研究中表现出良好的信效度（α=0.91）。

**数字资源（4题项）**
- DT1：我们公司拥有先进的数字技术基础设施
- DT2：我们公司建立了完善的数据管理平台
- DT3：我们公司配备了充足的数字化专业人才
- DT4：我们公司投入了大量资金用于数字化建设

**数字能力（4题项）**
- DT5：我们公司能够有效利用数字技术优化业务流程
- DT6：我们公司能够通过数据分析支持管理决策
- DT7：我们公司能够运用数字技术开发新产品/服务
- DT8：我们公司能够借助数字平台拓展新市场

**数字文化（4题项）**
- DT9：我们公司高层领导积极推动数字化变革
- DT10：我们公司员工普遍具有数字化意识
- DT11：我们公司鼓励尝试新的数字技术和工具
- DT12：我们公司形成了数据驱动的决策文化

### 3.2.2 组织韧性

组织韧性的测量借鉴Duchek（2020）开发的量表，包括预见能力、应对能力、适应能力三个维度，共12个题项。该量表在已有研究中表现出良好的信效度（α=0.89）。

**预见能力（4题项）**
- OR1：我们公司能够及时识别外部环境的潜在威胁
- OR2：我们公司能够准确预测行业发展趋势
- OR3：我们公司建立了有效的风险预警机制
- OR4：我们公司定期进行情景规划和压力测试

**应对能力（4题项）**
- OR5：我们公司能够在危机发生时快速做出响应
- OR6：我们公司能够有效调动资源应对突发事件
- OR7：我们公司各部门能够在危机中高效协作
- OR8：我们公司能够在危机中保持核心业务运转

**适应能力（4题项）**
- OR9：我们公司能够从危机事件中汲取经验教训
- OR10：我们公司能够根据环境变化调整战略方向
- OR11：我们公司能够将危机转化为发展机遇
- OR12：我们公司在经历危机后变得更加强大

### 3.2.3 创新绩效

创新绩效的测量借鉴Chen等（2019）开发的量表，共6个题项。该量表在已有研究中表现出良好的信效度（α=0.88）。

- IP1：与主要竞争对手相比，我们公司推出新产品的速度更快
- IP2：与主要竞争对手相比，我们公司新产品的数量更多
- IP3：与主要竞争对手相比，我们公司新产品的质量更高
- IP4：与主要竞争对手相比，我们公司新产品的市场表现更好
- IP5：我们公司能够持续进行技术和工艺创新
- IP6：我们公司的创新活动为企业带来了显著收益

### 3.2.4 环境动态性

环境动态性的测量借鉴Dess和Beard（1984）以及Jansen等（2006）的量表，共5个题项。该量表在已有研究中表现出良好的信效度（α=0.85）。

- ED1：我们所在行业的技术变化非常快
- ED2：我们所在行业的客户需求变化非常快
- ED3：我们所在行业的竞争格局变化非常快
- ED4：我们所在行业很难预测未来发展趋势
- ED5：我们所在行业的不确定性很高

### 3.2.5 控制变量

为排除其他因素的干扰，本研究控制了以下变量：

- **企业规模**：以企业员工人数的自然对数衡量
- **企业年龄**：以企业成立年限衡量
- **企业性质**：设置虚拟变量（国有=1，非国有=0）
- **行业类别**：设置虚拟变量

## 3.3 分析方法

### 3.3.1 为何选择PLS-SEM

本研究采用偏最小二乘结构方程模型（PLS-SEM）进行数据分析，主要基于以下考虑：

第一，PLS-SEM适用于探索性研究。本研究探讨数字化转型通过组织韧性影响创新绩效的机制，具有一定的探索性，PLS-SEM比CB-SEM更为适合（Hair et al., 2019）。

第二，PLS-SEM对样本分布要求较低。PLS-SEM不要求数据服从正态分布，对样本量的要求也相对较低（Hair et al., 2017）。

第三，PLS-SEM适用于包含多个潜变量的复杂模型。本研究模型涉及多个潜变量和多层次的中介、调节效应，PLS-SEM能够有效处理（Hair et al., 2019）。

### 3.3.2 SmartPLS 4操作说明

本研究使用SmartPLS 4.0软件进行PLS-SEM分析，主要步骤如下：

**步骤1：数据导入与模型构建**
- 将数据文件（CSV格式）导入SmartPLS
- 创建潜变量并关联相应的观测指标
- 绘制变量之间的路径关系

**步骤2：PLS算法计算**
- 设置参数：Path Weighting Scheme，Maximum Iterations=300，Stop Criterion=10^-7
- 运行PLS Algorithm，获得外部载荷、路径系数等初步结果

**步骤3：Bootstrap检验**
- 设置参数：Subsamples=5000，Confidence Interval Method=Bias-Corrected and Accelerated
- 运行Bootstrapping，获得路径系数的显著性检验结果

**步骤4：中介效应检验**
- 在Bootstrapping结果中查看Specific Indirect Effects
- 根据置信区间是否包含0判断中介效应是否显著

**步骤5：调节效应检验**
- 使用SmartPLS的调节效应分析功能
- 创建交互项（数字化转型×环境动态性）
- 检验交互项对组织韧性的影响

### 3.3.3 数据分析流程

本研究的数据分析遵循以下流程：

```
数据准备
    │
    ▼
描述性统计与相关分析
    │
    ▼
测量模型检验
├── 信度检验（α, CR）
├── 收敛效度（AVE, 载荷）
└── 判别效度（Fornell-Larcker, HTMT）
    │
    ▼

├── 共线性检验（VIF）

├── R²与f²效应量

    │
    ▼
假设检验
├── 直接效应检验（H1, H2, H3）
├── 中介效应检验（H4）
└── 调节效应检验（H5）
    │
    ▼
稳健性检验
```
