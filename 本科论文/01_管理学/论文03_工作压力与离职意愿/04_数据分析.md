## 4.3 假设检验

### 4.3.1 工作压力对离职意愿的主效应（H1）

采用层级回归分析检验工作压力对离职意愿的影响。在第一步纳入控制变量，第二步纳入自变量（工作压力）。

**表4-4 工作压力对离职意愿的回归分析**

| 变量 | Model 1（β） | Model 2（β） |
|------|--------------|--------------|
| **控制变量** | | |
| 性别 | 0.02 | 0.03 |
| 年龄 | -0.08 | -0.05 |
| 学历 | 0.11* | 0.09 |
| 工龄 | -0.12* | -0.08 |
| 行业（虚拟变量） | 略 | 略 |
| R² | 0.06 | |
| **自变量** | | |
| 工作压力 | | 0.46*** |
| ΔR² | | 0.20 |
| 总R² | 0.06 | 0.26 |
| F | 3.24** | 18.72*** |

注：*p<0.05, **p<0.01, ***p<0.001

结果显示，在控制人口统计学变量后，工作压力对离职意愿具有显著正向影响（β=0.46, p<0.001），工作压力的加入使R²增加了0.20，解释了20%的额外方差。**假设H1获得支持**。

### 4.3.3 工作满意度的中介效应（H3）

采用PROCESS宏Model 4检验工作满意度的中介效应。Bootstrap抽样5000次。

**表4-6 中介效应检验结果**

| 效应类型 | 效应值 | Boot SE | 95% CI下限 | 95% CI上限 |
|----------|--------|---------|------------|------------|
| 总效应（c） | 0.46 | 0.04 | 0.38 | 0.54 |
| 直接效应（c'） | 0.27 | 0.05 | 0.18 | 0.36 |
| 间接效应（a×b） | 0.19 | 0.03 | 0.14 | 0.25 |
| 中介效应占比 | 41.3% | | | |

结果显示：

（1）工作压力对离职意愿的总效应显著（c=0.46, 95% CI=[0.38, 0.54]）。

（2）工作压力对工作满意度的影响显著（a=-0.52, p<0.001）。

（3）控制工作压力后，工作满意度对离职意愿的影响显著（b=-0.37, p<0.001）。

（4）工作压力通过工作满意度影响离职意愿的间接效应为0.19，95%置信区间为[0.14, 0.25]，不包含0，中介效应显著。

（5）控制工作满意度后，工作压力对离职意愿的直接效应仍然显著（c'=0.27, p<0.001），说明工作满意度起**部分中介**作用。

**假设H3获得支持**。中介效应占总效应的41.3%，说明工作压力对离职意愿的影响有相当部分是通过降低工作满意度实现的。

### 4.3.4 组织支持感知的调节效应（H4）

采用PROCESS宏Model 1检验组织支持感知对工作压力-工作满意度关系的调节效应。自变量和调节变量均进行中心化处理。

**表4-7 调节效应检验结果**

| 变量 | β | SE | t | p |
|------|------|------|------|------|
| 工作压力（X） | -0.38 | 0.05 | -7.60 | <0.001 |
| 组织支持感知（W） | 0.48 | 0.04 | 12.00 | <0.001 |
| X×W（交互项） | 0.14 | 0.04 | 3.50 | <0.001 |
| R² | 0.48 | | | |
| ΔR²（交互项贡献） | 0.02 | | | |

结果显示，工作压力与组织支持感知的交互项对工作满意度的影响显著（β=0.14, p<0.001），表明组织支持感知显著调节工作压力与工作满意度的关系。**假设H4获得支持**。

交互效应的增量解释方差（ΔR²）为0.02，虽然数值不大，但在组织行为学研究中属于中等水平的调节效应。

**简单斜率分析**

为进一步理解调节效应的模式，进行简单斜率分析，检验在高（M+1SD）与低（M-1SD）组织支持条件下，工作压力对工作满意度的影响差异。

**表4-8 简单斜率分析**

| 组织支持水平 | 简单斜率 | SE | t | p |
|--------------|----------|------|------|------|
| 低组织支持（M-1SD） | -0.52 | 0.06 | -8.67 | <0.001 |
| 均值 | -0.38 | 0.05 | -7.60 | <0.001 |
| 高组织支持（M+1SD） | -0.24 | 0.06 | -4.00 | <0.001 |

结果显示：

在低组织支持条件下，工作压力对工作满意度的负向影响较强（β=-0.52, p<0.001）。

在高组织支持条件下，工作压力对工作满意度的负向影响较弱（β=-0.24, p<0.001）。

两条简单斜率均显著，但斜率差异也显著（Δβ=0.28, p<0.001），证实了调节效应的存在。

这一结果符合"缓冲假说"的预测：组织支持作为一种工作资源，能够缓冲工作压力对员工态度的负面影响。

### 4.3.5 有调节的中介模型检验

采用PROCESS Model 7检验完整的有调节的中介模型。

**表4-9 有调节的中介效应**

| 组织支持水平 | 间接效应 | Boot SE | 95% CI |
|--------------|----------|---------|--------|
| 低组织支持（M-1SD） | 0.24 | 0.04 | [0.17, 0.32] |
| 均值 | 0.18 | 0.03 | [0.13, 0.24] |
| 高组织支持（M+1SD） | 0.11 | 0.03 | [0.06, 0.17] |

有调节的中介指数（Index of Moderated Mediation）= 0.06，95% CI = [0.02, 0.10]，不包含0，表明有调节的中介效应显著。

结果表明：工作压力通过工作满意度影响离职意愿的间接效应受到组织支持感知的调节。在低组织支持条件下，间接效应为0.24；在高组织支持条件下，间接效应降低至0.11。这意味着，组织支持不仅能缓冲压力对满意度的直接负面影响，还能通过这一缓冲机制间接降低压力导致的离职意愿。
