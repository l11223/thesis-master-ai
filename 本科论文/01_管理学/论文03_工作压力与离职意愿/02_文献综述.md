# 第二章 文献综述与研究假设

## 2.1 工作压力研究综述

### 2.1.1 概念界定

工作压力（Work Stress）是组织行为学与职业健康心理学的核心研究议题。从概念界定来看，学界存在三种主要取向：

**刺激取向**：将压力视为外部环境刺激，关注工作环境中的压力源（stressors），如工作负荷、角色冲突、人际冲突等。这一取向便于识别和测量具体的压力因素。

**反应取向**：将压力视为个体对环境刺激的生理与心理反应，关注压力症状如焦虑、疲劳、身心俱疲等。Selye的一般适应综合征理论是这一取向的代表。

**交互取向**：将压力视为个体与环境之间的动态交互过程。Lazarus和Folkman（1984）的认知评价理论是这一取向的代表，强调个体对压力源的主观评价（初级评价：是否构成威胁；次级评价：是否有资源应对）决定了压力反应的性质与强度。

本研究采用交互取向的视角，将工作压力界定为：员工因感知到工作要求超出自身应对资源而产生的紧张状态。这一界定强调压力的主观感知性质，有利于解释为何面对相同工作条件，不同员工的压力反应存在差异。

### 2.1.2 工作压力的类型划分

Cavanaugh等（2000）基于挑战-阻碍压力框架，将工作压力源区分为两类：

**挑战性压力源（Challenge Stressors）**：包括工作负荷、时间压力、工作复杂性、职责范围等。这类压力源虽然带来紧张，但也被员工视为成长与发展的机会，可能激发积极的应对行为与工作投入。

**阻碍性压力源（Hindrance Stressors）**：包括角色模糊、角色冲突、组织政治、工作不安全感等。这类压力源被员工视为阻碍目标达成与职业发展的障碍，主要引发消极的情绪与行为反应。

元分析研究（Podsakoff et al., 2007）证实，两类压力源对员工态度与行为的影响存在差异：挑战性压力源与工作满意度、组织承诺呈微弱正相关或无显著关系，而阻碍性压力源与之呈显著负相关。本研究关注的工作压力主要指阻碍性压力源。

### 2.1.3 工作压力的后果

工作压力对员工与组织产生多方面的影响：

**个体层面**：高工作压力与焦虑、抑郁、工作倦怠、身心疾病等负面健康后果显著相关。世界卫生组织已将工作倦怠列入《国际疾病分类》第11版（ICD-11）。

**态度层面**：工作压力与工作满意度、组织承诺呈负相关，与离职意愿呈正相关（Jamal, 1990）。

**行为层面**：高压力员工可能表现出缺勤、工作绩效下降、人际冲突增加、反生产行为等问题。

**组织层面**：员工压力累积导致人才流失、生产效率下降、医疗保险成本上升、组织声誉受损等后果。

## 2.2 离职意愿研究综述

### 2.2.1 概念界定

离职意愿（Turnover Intention）是指员工产生的离开当前组织的想法或计划。Mobley（1977）将离职意愿界定为"员工经历工作不满后，产生退缩认知，进而发展出离职意向与寻找其他工作意向的心理过程"。

离职意愿与实际离职行为密切相关但又有区别。研究表明，离职意愿是预测实际离职行为的最佳指标之一，两者之间的相关系数通常在0.50左右。从管理干预角度看，离职意愿作为实际离职的前兆信号，具有早期预警的价值。

### 2.2.2 离职意愿的前因变量

Price和Mueller的离职模型将离职意愿的前因归纳为以下几类：

**环境因素**：劳动力市场状况、外部就业机会、行业流动性等。当外部机会充足时，员工更容易将不满转化为离职意愿。

**组织因素**：薪酬公平、晋升机会、组织支持、组织公平、领导风格、工作条件等。

**工作因素**：工作本身的特征，如自主性、挑战性、角色清晰度、工作压力等。

**个体因素**：年龄、工龄、学历、家庭状况等人口统计学变量，以及工作卷入、职业承诺等个体差异变量。

**态度变量**：工作满意度、组织承诺被认为是离职意愿最直接的前因变量。大量研究证实，工作满意度与组织承诺对离职意愿具有显著负向影响。

### 2.2.3 工作压力与离职意愿的关系

工作压力与离职意愿之间的正向关系已得到大量实证研究的支持。Podsakoff等（2007）的元分析发现，阻碍性压力源与离职意愿的相关系数为0.32（经校正）。

这一关系的形成机制可从多个理论视角得到解释：

**资源保存理论视角**：高压力工作消耗员工的心理资源，当资源枯竭时，员工倾向于通过离开高压环境来保护剩余资源。

**期望-价值理论视角**：当员工感知到压力带来的成本（身心损耗）超过工作带来的价值（薪酬、发展等）时，离职成为理性选择。

**工作退缩理论视角**：离职意愿是员工工作退缩的一种表现形式，与缺勤、心理退缩等行为具有相似的心理根源。

## 2.3 工作满意度研究综述

### 2.3.1 概念界定

工作满意度（Job Satisfaction）是员工对其工作的整体情感反应与评价性判断。Locke（1976）将其定义为"个体评价工作或工作经历后产生的愉悦或积极的情绪状态"。

工作满意度可以从整体与分面两个层次进行测量。整体工作满意度关注员工对工作的总体评价，而分面满意度则区分薪酬满意度、晋升满意度、上司满意度、同事满意度、工作本身满意度等不同维度。

### 2.3.2 工作满意度的中介角色

在压力-离职关系中，工作满意度被认为扮演重要的中介角色。其逻辑链条如下：

工作压力首先影响员工的工作态度。高压力损耗员工的心理资源，引发消极情绪，降低对工作的积极评价，表现为工作满意度下降。

工作满意度的下降进一步引发离职意愿。根据态度-行为一致性原则，当员工对工作不满时，会产生改变现状的动机，离开当前组织成为可能的选择。

这一中介路径在Mobley（1977）的离职过程模型中得到体现：工作不满是离职过程的起点，不满引发对当前工作的评价、离职成本与收益的权衡，最终形成离职意愿。

## 2.4 组织支持感知研究综述

### 2.4.1 概念界定

组织支持感知（Perceived Organizational Support, POS）是指员工对组织重视其贡献、关心其福祉程度的整体信念。Eisenberger等（1986）提出这一概念，认为员工会将组织拟人化，形成对组织"是否关心自己"的整体感知。

组织支持感知的形成受多种因素影响，包括：组织公平（特别是程序公正）、上级支持、奖励与工作条件、工作保障、培训与发展机会等。

### 2.4.2 组织支持的缓冲效应

社会支持研究领域的"缓冲假说"提出，社会支持能够削弱压力源对个体心理健康的负面影响。将这一思想应用于组织情境，组织支持感知可能在工作压力与其消极后果之间起调节作用。

这一调节效应的机制在于：当员工感知到组织的支持与关怀时，他们更有信心应对工作压力（认知层面），也能够获得更多的应对资源（资源层面），从而削弱压力的消极影响。

Rhoades和Eisenberger（2002）的元分析为这一缓冲效应提供了间接支持：组织支持感知与压力、倦怠等负面状态呈显著负相关，表明高组织支持环境有助于降低压力的不良后果。

## 2.5 理论基础

### 2.5.1 工作要求-资源模型（JD-R Model）

工作要求-资源模型（Job Demands-Resources Model）是解释工作压力与员工状态关系的重要理论框架。该模型的核心观点包括：

**工作要求（Job Demands）**：指工作中需要员工付出持续生理或心理努力的各类因素，如工作负荷、时间压力、角色冲突等。工作要求消耗员工的能量与资源。

**工作资源（Job Resources）**：指有助于员工实现工作目标、减少工作要求消耗、促进个人成长的因素，如组织支持、自主性、反馈、职业发展机会等。

**双路径过程**：模型提出两条平行路径——
- 能量损耗路径：高工作要求→资源耗竭→负面后果（倦怠、健康问题、离职意愿）
- 动机激发路径：充足工作资源→内在动机→积极后果（工作投入、绩效、留任）

**交互效应**：工作资源能够缓冲工作要求的负面影响（缓冲假说），同时工作要求也能强化工作资源的积极效应（促进假说）。

本研究基于JD-R模型，将工作压力视为一种工作要求，将组织支持感知视为一种工作资源，检验压力通过降低满意度（一种资源损耗指标）导致离职意愿的路径，以及组织支持对压力-满意度关系的缓冲效应。

### 2.5.2 社会交换理论

社会交换理论为理解组织支持感知的作用提供了补充视角。根据互惠规范，当员工感知到组织的支持与关怀时，会产生回报组织的义务感，表现为更高的满意度、更强的承诺、更低的离职意愿。

同时，在社会交换框架下，组织支持感知意味着员工与组织之间建立了高质量的交换关系。这种关系质量为员工在面对工作压力时提供了心理缓冲——因为员工相信组织会在其困难时提供帮助。

## 2.6 研究假设与模型

### 2.6.1 工作压力与离职意愿

基于上述分析，工作压力对离职意愿的正向影响有充分的理论支撑与实证基础。高压力工作损耗员工的心理资源，引发消极情绪与工作体验，促使员工产生逃离当前工作环境的想法。

**H1：工作压力对员工离职意愿具有显著正向影响。**

### 2.6.2 工作压力与工作满意度

工作压力对工作满意度的负向影响可从资源损耗的视角理解。高压力意味着工作要求超出员工的应对能力，导致心理资源持续消耗、负面情绪累积、工作体验恶化，最终表现为工作满意度的下降。

**H2：工作压力对员工工作满意度具有显著负向影响。**

### 2.6.3 工作满意度的中介作用

根据JD-R模型的能量损耗路径与Mobley的离职过程理论，工作压力首先通过消耗心理资源降低工作满意度，满意度的下降进一步引发离职意愿。工作满意度是连接压力与离职意愿的心理中介机制。

**H3：工作满意度在工作压力与离职意愿之间起中介作用。**

### 2.6.4 组织支持感知的调节作用

根据JD-R模型的缓冲假说与社会支持的压力缓冲理论，组织支持感知作为一种重要的工作资源，能够削弱工作压力对员工态度的负面影响。

当员工感知到高水平的组织支持时，他们拥有更多的应对资源（如情感支持、信息支持、工具支持），也更有信心应对工作压力，因此压力对满意度的负面影响被削弱。反之，在低组织支持条件下，员工缺乏应对资源，压力的负面影响更为显著。

**H4：组织支持感知调节工作压力与工作满意度的关系。具体而言，在高组织支持条件下，工作压力对工作满意度的负向影响较弱；在低组织支持条件下，该负向影响较强。**

### 2.6.5 研究模型

综合上述假设，本研究的理论模型如下：

```
                    ┌─────────────────┐
                    │  组织支持感知    │
                    │      (W)        │
                    └────────┬────────┘
                             │ H4
                             ↓
┌─────────────┐   H2    ┌─────────────┐   H3b   ┌─────────────┐
│   工作压力   │ ──────→ │  工作满意度  │ ──────→ │  离职意愿   │
│     (X)     │         │     (M)     │         │     (Y)     │
└─────────────┘         └─────────────┘         └─────────────┘
       │                                               ↑
       │                     H1                        │
       └───────────────────────────────────────────────┘
```

该模型整合了中介效应与调节效应，形成"有调节的中介模型"（Moderated Mediation）。
